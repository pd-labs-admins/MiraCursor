# MiraCursor

**オンライン会議のプレゼンテーションで、「いま説明している場所」をはっきり伝えるためのツールです。** 「Mira」はスペイン語で「見て！」という意味があるそうで、ここから「MiraCursor」という名前にしました。

MiraCursor は macOS と Windows で使える常駐型のアプリです。設定したキーを長押しするだけで画面上のマウスカーソルの周りを強調表示できます。起動してもウインドウは開かず、macOS ではメニューバー、Windows ではタスクトレイ（通知領域）にアイコンだけが表示されます。

## できること

MiraCursor にはいくつかの「強調表示モード」があります。設定で決めたキー（トリガーキー）を長押しすると、そのキーに割り当てたモードが始まります。同時に使えるモードは 1 つだけです。

### カスタムカーソル

マウスカーソルそのものを通常のカーソル・指差し・指差し棒などの画像や、カーソルの周りに半透明の色を重ねる「ハイライトカーソル」、カーソルの位置を拡大して表示する「ズームカーソル」、任意の画像に変更することができます。特定のウインドウだけを画面共有しているときでも相手に見えます。カーソルの動きに合わせた残像や、クリックした位置に波紋も表示できます。

![image](assets/img/custom_cursor.png)

### ペン

マウスのドラッグで画面に線を描けます。左ボタンと右ボタンで別々の色・太さ・線の種類を使えます。45 度単位のまっすぐな線を描く「直線モード」もあります。描いた線は、モードを終えるとすべて消えます。描いた内容を含めて画面をキャプチャし、クリップボードやファイルに保存することもできます。

![image](assets/img/pen.png)

### スポットライト

画面全体を薄暗くして、マウスカーソルの周りだけを明るく表示します（以前の「ライト」）。カーソルを動かすと、明るい部分も一緒に動きます。カーソルの周りに半透明の色を重ねる「ハイライト」は、カスタムカーソルの「ハイライトカーソル」に移りました。

![image](assets/img/light.png)

### ウインドウサイズ

クリックしたウインドウの大きさを、登録した大きさ（1920 x 1080・1024 x 768 など）にまとめて変えます。資料用の画像を、いつも同じ大きさのウインドウで撮影したい場合などに使います。

### ズーム

マウスカーソルの周りを拡大して表示します（ルーペ）。カーソルを中心にした十字線や、カーソル位置の X / Y 座標も表示できます。カーソル位置の色を `RGB(255,0,0)` や `#FF0000` の形式で表示し、クリックで色の値を選んだ形式でクリップボードにコピーすることもできます。

![image](assets/img/zoom.png)

### キーモニタ

キーボードで押したキーを画面に表示します（新規）。「a」のような 1 つのキーだけでなく、「⇧ + A」（Windows は「Shift + A」）のような修飾キーとの組み合わせも表示できます。表示のしかたは、押したキーのアイコンを並べる「スクロール」と、キーボードの絵で押したキーを強調する「キーボード」から選べます。タイピング数の統計情報（1分間・5分間・10分間・1時間・合計）と、削除キー（Backspace / DEL）を押した回数も表示できます。押したキーは、アプリにそのまま届きます。

## 注意点：画面共有時の見え方

Cisco Webex、Slack、Microsoft Teams、Zoomなどのコミュニケーションツールを使い、オンライン会議で画面共有する場合、共有範囲に応じて「相手側の見え方」は以下となります。「ウインドウ共有」を多用される方はカスタムカーソルを中心にご利用ください。

- デスクトップ共有
    - ペン・スポットライト・ズームなどの効果は共有相手にも表示されます。
    - カスタムカーソルも共有相手に表示されます。
- ウインドウ共有
    - ペン・スポットライト・ズームなどの効果は共有相手にも **表示されません**
    - カスタムカーソルも共有相手に表示されます。

以前は、ペン・ズーム・キーモニタ・スポットライトのモードを開始したときに、OS の通知で「ウインドウ共有時、相手には効果が表示されません。」という注意書きを表示できました（「管理」タブの「表示」グループの「開始時に注意書きを表示」）が、この設定と通知は廃止しました。

| Windows | `MiraCursor-x.y.z-windows-x64.msi` |

### macOS

1. `MiraCursor-x.y.z-macos.dmg` を開きます。
2. `MiraCursor.app` を `Applications`（アプリケーション）フォルダへドラッグします。
3. アプリケーションフォルダの **MiraCursor** を起動します。
4. 初回起動時に「入力監視」の許可を求められます。[必要な権限](#必要な権限) を参考に許可してください。

> **「開発元を検証できないため開けません」と表示される場合**
> MiraCursor は Apple の公証（notarization）を受けていないため、初回起動時にこのメッセージが出ることがあります。次のどちらかの方法で開いてください。
>
> - **システム設定 → プライバシーとセキュリティ** を開き、下の方にある「このまま開く」をクリックする
> - ターミナルで次のコマンドを実行してから、もう一度起動する
>
>   ```sh
>   xattr -dr com.apple.quarantine /Applications/MiraCursor.app
>   ```

### Windows

1. `MiraCursor-x.y.z-windows-x64.msi` をダブルクリックします。
2. インストールが終わると MiraCursor が起動し、タスクトレイにアイコンが表示されます。スタートメニューにも登録されます。
   - インストール先は `%LOCALAPPDATA%\Programs\MiraCursor` です（ユーザーごとのインストールなので、管理者権限は不要です）。

> **「Windows によって PC が保護されました」と表示される場合**
> MiraCursor にはコード署名をしていないため、Microsoft Defender SmartScreen の警告が出ることがあります。「詳細情報」→「実行」を選ぶとインストールできます。

> **インストールせずに使う場合**
> `MiraCursor-x.y.z-windows-x64.zip` を展開し、`MiraCursor.exe` を実行してください（ポータブル版）。ポータブル版は自動アップデートされません。新しいバージョンが出ると通知が表示されます。

## 必要な権限

### macOS

| 権限 | 必要なとき | 理由 |
| --- | --- | --- |
| **入力監視** | **常に必要** | どのアプリを使っているときでも、トリガーキーの長押しと ESC キーを検出するため |
| **画面収録** | ズーム・ペンのキャプチャを使うときだけ | マウスカーソルの周りを拡大表示し、カーソル位置の色を読み取るため / 画面をキャプチャするため |
| **マイク** | 設定の「ウィジェット」（以前の「マイクレベル」）の「マイク入力」を有効にするときだけ | マイクの入力レベル（音量）を画面のアイコンに表示するため（音声は録音・保存しません） |
| **アクセシビリティ** | クリップボード履歴の「テキスト選択時の動作」「画像選択時の動作」が「貼り付け」「クリップボードと貼り付け」のとき・ウインドウサイズモードを使うときだけ | 選んだ履歴を、選択中のアプリケーションへ貼り付ける（⌘V を送る）ため / ほかのアプリケーションのウインドウの大きさを変えるため |

クリップボード履歴で貼り付ける場合・ウインドウサイズモードを除き、アクセシビリティの権限は必要ありません。MiraCursor はキー入力を読み取るだけで、入力の内容を記録したり、送信したり、書き換えたりはしません。

**許可のしかた**

1. **システム設定 → プライバシーとセキュリティ → 入力監視**（ズーム・ペンのキャプチャを使う場合は **画面収録とシステムオーディオ録音**、ウィジェットのマイク入力を使う場合は **マイク** も）を開きます。
   メニューバーの MiraCursor のアイコンから開くこともできます。
2. 一覧の **MiraCursor** をオンにします。一覧に無い場合は「＋」で `/Applications/MiraCursor.app` を追加します。
3. メニューバーのアイコン →「MiraCursor を再起動」を選びます。

権限が足りないときは、メニューバーのアイコンが ⚠️ に変わります（これまでどおりです）。

### Windows

**特別な権限は必要ありません**（管理者権限も不要です）。

ただし、設定の「ウィジェット」の「マイク入力」を使う場合は、Windows の **設定 → プライバシーとセキュリティ → マイク** で「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」をオンにしてください。

## 使い方

### 基本の操作

1. MiraCursor を起動しておきます（メニューバー / タスクトレイにアイコンが出ていれば起動中です）。
2. 使いたいモードの **トリガーキーを長押し** します（既定は 1.5 秒）。
3. 強調表示が始まります。
4. トリガーキーを離すと終わります（終了方法が「キーを離す」（既定）の場合。「キーの長押し」にしたトリガーで始めた場合は、もう一度トリガーキーを長押しすると、「ESCキー」にしたトリガーで始めた場合は **ESC** キーで、「メニュー」にしたトリガーで始めた場合は、メニューで実行中のモード名を選ぶと終わります。[終了方法](#終了方法) を参照）。どの方法で始めた場合も、**ESC** キーを「強制終了の長押し」の時間（既定 1.5 秒）だけ長押しすると強制的に終わります。

メニューバー / タスクトレイのアイコンのメニューでモード名を選んで始めることもできます（トリガーキーが無いモードも始められます）。この場合の終了方法は「メニュー」です（v0.0.5 までは「トグル動作」）。もう一度メニューで同じモード名を選ぶと終わり、**ESC** やトリガーキーでは終わりません（**ESC** キーの「強制終了の長押し」（既定 1.5 秒）を除く）。使っている間は、他のモードのトリガーキーを長押ししても切り替わりません。ただし、そのモードにトリガーキーが「なし」のトリガーがある場合は、そのトリガーの終了方法（「ESCキー」か「メニュー」）で始まります。メニューで使っていないモードを選ぶと、そのモードに切り替わります。使っているモードには、メニューのモード名にチェックマークが付きます。

メニューバー / タスクトレイのアイコンには、MiraCursor のアイコンに状態のバッジが重なって表示されます（どのモードでも同じです）。モードを使っていないときは時計の針の付いた黄色の丸（「退席中」のようなアイコン）、モードを使っている間（キャプチャのショートカットキーで始めたキャプチャモードを含む）はチェックマークの付いた緑色の丸（「連絡可能」のようなアイコン）です。以前の設定「アプリケーションのアイコンを変更」はなくなりました。

メニューの並びは、上からモードの一覧 → **クリップボード履歴**（[クリップボード履歴](#クリップボード履歴) を参照）→ **定型文**（[定型文](#定型文) を参照）→ **MiraPaint** → **ウィジェット**（以前の「マイクレベル」）→ 設定… / アップデートを確認… → 終了 です。「ウィジェット」は、[ウィジェット](#ウィジェット) が有効な間はチェックマークが付き、選ぶと有効 / 無効を切り替えます（設定の「ウィジェット」タブの「全般」の「有効」と同じです）。「MiraPaint」を選ぶと MiraPaint が開きます。クリップボードに画像がある場合はその画像を、無い場合は白い無地の画像（1280 × 720）を開きます。画面をキャプチャするには、キャプチャモード（[キャプチャ](#キャプチャ) を参照）を使います。キャプチャモードは [キャプチャのショートカット](#キャプチャのショートカット) でも開始できます。

#### メニューを開くショートカット

**メニューを開くショートカット**（新規）を押すと、MiraCursor のメニューが **マウスカーソルの位置** に開きます。既定は macOS が **⌥⇧M**（Option+Shift+M）、Windows が **Alt+Shift+M** です（以前は macOS が ⌃⌥M、Windows が Ctrl+Alt+M。以前に変更・保存した値はそのまま使います）。

- モードを使っている間（ペンモードなどで、画面のクリックがモードに使われている間）でも、メニューからモードを終わらせたり、MiraPaint・設定などの他の項目を選んだりできます。
- Windows でタスクトレイのアイコンが通知領域の「隠れているインジケーターを表示」（「^」）の中に入っていて、すぐにクリックできない場合でも、メニューを開けます。
- 設定の「ショートカット」タブ（新設。以前は「全般」タブ）の「MiraCursor」グループ（以前の「メニュー」グループ）の「ツールメニューを開く」（以前の「メニューを開くショートカット」）で変えられます。ボタンをクリックしてから、修飾キー（macOS は Control・Option・Command のどれか、Windows は Ctrl か Alt）を押しながらキーを押すと記録されます（**ESC** で取り消し。記録中は欄の枠が強調色になります）。欄の右の「✕」（キーが設定されているときだけ表示。以前の「なし」のボタン）を押すと未設定になり、ショートカットでは開かなくなります。未設定の欄は、薄い文字で「未設定（クリックして記録）」と表示します。他の項目で使っているキーを設定すると、その項目は未設定になり、欄の下に「「<項目名>」から移しました」と数秒間表示します。
- ショートカットキーには Shift を含む組み合わせも使えます（例: macOS は ⇧⌘X、Windows は Win + Shift + X・Ctrl + Shift + X。Windows は Windows キーも使えます。Windows 自身のショートカット（Win + E など）と重ならないキーを選んでください）。記録している間は、押している修飾キーをボタンに表示します。
- 押したキーは、他のアプリにもそのまま伝わります。他のアプリのショートカットと重なる場合は、別のキーに変えてください。

#### キャプチャのショートカット

設定の「キー設定」タブの「キャプチャ」グループの **キャプチャの開始** のショートカットキー（既定は macOS が ⌥⇧X（Option + Shift + X）、Windows が Alt + Shift + X。以前は macOS が ⌥⇧C、Windows が Alt + Shift + C、さらに以前は macOS が ⇧⌘X、Windows が Ctrl + Shift + X）を押すと、キャプチャモードを開始します（メニューのキャプチャモードの項目と同じです）。キャプチャモードの実行中に押すと終了します。撮影する対象やキャプチャ後の動作などは、「キャプチャ」タブの設定とキャプチャモードの選択ウインドウに従います（[キャプチャ](#キャプチャ) を参照）。実行中の他のモードは終了します。記録の方法は「ツールメニューを開く」と同じです。同じキーを他の項目に設定すると、元の項目は「なし」になります。

以前は「選択範囲から文字/QRコード読み取り」「選択範囲」「クリックしたウインドウ」「アクティブなデスクトップ」「全てのデスクトップ」ごとに、キャプチャモードを始めずにすぐに撮影・読み取りをするショートカットキーがありましたが、廃止しました（選択範囲から文字/QRコードを読み取るには、キャプチャモードの選択ウインドウの「文字認識」を使います）。

「キー設定」タブのショートカットキーは、上から次のグループに並びます（どれも、同じキーを他の項目に設定すると元の項目は「なし」になり、一番下の「既定値に戻す」で、これらのショートカットキーをまとめて初期値に戻せます）。

| グループ | 項目 | 既定 | 内容 |
| --- | --- | --- | --- |
| **MiraCursor**（以前の「メニュー」） | ツールメニューを開く | macOS ⌥⇧M / Windows Alt + Shift + M | マウスカーソルの位置に MiraCursor のメニューを開きます（[メニューを開くショートカット](#メニューを開くショートカット) を参照）。 |
| | 設定ウインドウを開く（新規） | なし | MiraCursor の設定ウインドウを開きます（メニューの「設定…」と同じ）。 |
| **キャプチャ** | キャプチャの開始 | macOS ⌥⇧X / Windows Alt + Shift + X | キャプチャモードを開始します（実行中なら終了します）。 |
| **MiraPaint**（新規） | MiraPaintを開く | なし | MiraPaint を開きます（メニューの「MiraPaint」と同じ）。クリップボードに画像がある場合はその画像を、無い場合は新しい画像（新規作成）で開きます。 |

**開く（新規）:** 「キー設定」タブの一番下の「開く」グループの **テキストの保存先** / **画像の保存先**（既定: なし）を押すと、「管理」タブのテキスト・画像の保存先のディレクトリを Finder / エクスプローラーで開きます（無い場合は作ります）。

**重複の注意書き（新規）:** 「キー設定」のショートカットキー（ツールメニューを開く・設定ウインドウを開く・キャプチャの開始・MiraPaintを開く・ウインドウサイズの開始・ウィジェット・クリップボード）が、OS や他のアプリケーションのショートカットキーと重なっている場合は、キーの欄の下に注意書きを表示します。macOS はシステム設定の「キーボードショートカット」で有効なものと、⌘C・⌘V などの多くのアプリケーションで使われるものと比べます。Windows は Windows の主なショートカットキー（Win + L・Alt + Tab など）、Ctrl + C などの多くのアプリケーションで使われるもの、ほかのアプリケーションが登録しているグローバルなショートカットキー（ホットキー）と比べます。アプリケーションの中だけで使うショートカットキーなど、調べられないものもあります。
| **ウィジェット**（以前の「システム状態」。さらに以前は「マイクレベル」） | 有効/無効の切り替え | なし | [ウィジェット](#ウィジェット) の有効 / 無効を切り替えます（メニューの「ウィジェット」と同じです）。 |
| **クリップボード** | 履歴（以前の「履歴の表示」） | なし | マウスカーソルの位置にクリップボード履歴のメニューを開きます（[クリップボード履歴](#クリップボード履歴) を参照）。 |
| | 定型文（新規） | なし | マウスカーソルの位置に定型文の選択メニューを開きます（[定型文](#定型文) を参照）。 |

### クリップボード履歴

**クリップボード履歴**（新規）を使うと、クリップボードへコピーしたテキスト・画像を記録しておき、MiraCursor のメニューから選んでもう一度使えます。モードではないため、トリガーキーはありません。

1. 設定の「クリップボード履歴」タブ（サイドバーの「共通」の「MiraPaint」の下）の「全般」グループの「有効」をオンにします（既定は無効です。以前は「履歴」グループにありました）。オンにしている間にクリップボードへコピーされたデータを記録します（オンにする前からクリップボードにあったデータは記録しません）。
2. メニューバー / タスクトレイのアイコンのメニュー（またはメニューを開くショートカット）の **クリップボード履歴**（モードの一覧の下）にマウスポインタを重ねると、履歴が番号付きで並びます（macOS は行ごとに青と青緑を交互にした番号のバッジと「Apple」、Windows は「1:Apple」のように表示し、1 行おきに背景を薄い青にします。どの行も選べる同じ意味の項目です）。長いテキストは先頭だけ、画像は「(Image)」と表示します。項目にマウスポインタを重ねている間は、テキストはその内容をプレビュー（テキストで表示するウインドウ。定型文と同じもの。以前はテキストの項目では表示しませんでした）に、画像はその画像のサムネイルを表示します（「プレビュー」グループの「有効」が有効な場合。表示する位置は自動で決まり、開いているメニューのすぐ横（右か左）に、メニューと重ならないように表示します。大きさは「幅」「高さ」に従います。サムネイルは縦横比を保って「幅」×「高さ」に収まる大きさで表示します。以前は「キャプチャ」タブの「プレビュー」の「サイズ」に従っていました）。
3. 項目を選ぶと、テキストは「テキスト選択時の動作」、画像は「画像選択時の動作」の設定に従って使います。

| 設定 | 内容 |
| --- | --- |
| **有効**（「全般」グループ。以前は「履歴」グループ。既定: 無効） | オンの間、クリップボードへコピーされたデータを記録します。パスワード管理アプリなどが記録しないよう指定したデータは記録しません。 |
| **テキスト選択時の動作**・**画像選択時の動作**（「全般」グループ。どちらも既定: クリップボード） | テキスト（履歴・定型文）を選んだときと、画像（履歴・定型文）を選んだときの動作を、それぞれ選びます。**クリップボード**: 選んだデータをクリップボードへコピーします（コピーしたデータも一番新しい履歴として記録します）。**貼り付け**: 選んだデータを選択中のアプリケーションへ貼り付けます（クリップボードは貼り付けた後で元に戻します）。**クリップボードと貼り付け**: その両方を行います。macOS で貼り付けるには「アクセシビリティ」の権限が必要です（権限が無い場合は、クリップボードへコピーするだけにします）。Windows では、管理者として実行しているアプリケーションには貼り付けられない場合があります。 |
| **プレビュー**（「全般」の下。以前は「定型文」タブにありました。その前の名前は「情報ウインドウ」） | クリップボード履歴・定型文の項目にマウスポインタを重ねている間、テキストはその内容をテキストで表示するウインドウ（黒の半透明・白い文字）に、画像はサムネイルで表示します（画像の透明な部分は、透過して表示します。以前の macOS 版は黒で表示していました）。その設定です。このグループの設定は、テキストのプレビューと画像のサムネイルの両方に適用します。表示する位置は自動で決まります（以前の「位置」の設定は無くなりました）。開いているメニュー（メニュー・クリップボード履歴のメニュー・定型文の選択メニュー）のすぐ横に、メニューと重ならないように表示します。右か左のうち、元のメニュー（そのメニューを開いたメニュー）が無い側に表示し、画面に収まらない場合は反対側に表示します。上下は、マウスポインタを重ねている項目の高さを中心にし、画面からはみ出さないようにします。設定の調整中の見本のように、メニューを開いていないときは、マウスカーソルのあるディスプレイの右端（上下の中央）に表示します。 |
| 　**有効**（既定: 有効） | 無効にすると、テキストのプレビューも画像のサムネイルも表示しません（画面共有中などに意図せず内容が画面に表示されることがなくなります）。以前の「サムネイル画像を表示」は無くなり、画像もこの設定に従います。 |
| 　**幅**・**高さ**（既定: 400 × 200。macOS は pt、Windows は px） | テキストのプレビューと画像のサムネイルの大きさです。サムネイルは縦横比を保って「幅」×「高さ」に収まる大きさで表示します（以前は「キャプチャ」タブの「プレビュー」の「サイズ」に従っていました）。調整している間は、見本の文章（『不思議の国のアリス』の冒頭）を書いたプレビューを実際の大きさで表示します（フォントなどを変えたときも表示します）。 |
| **テキストのプレビュー**（新規。「プレビュー」の下） | テキストのプレビューだけに適用する設定です（画像のサムネイルには適用しません）。 |
| 　**メニューに表示する文字数**（既定: 40 文字。10〜100、5 刻み） | メニューの「クリップボード履歴」「定型文」に、テキストを先頭から何文字まで表示するかです。見た目の 1 文字を 1 として数え、全角・半角（2 バイト文字・1 バイト文字）を区別しません（「あ」も「A」も、絵文字も 1 文字）（以前は「全般」グループ。その前は 40 文字に固定で、少し前までは「定型文」の「プレビュー」グループにありました）。 |
| 　**折り返して表示**（既定: 有効。以前は無効） | 有効にすると、幅に収まらない行を折り返します。無効の場合は、収まらない部分を「…」で省略します。高さに収まらない行は表示しません。 |
| 　**フォントの種類**・**フォントサイズ**（既定: システムフォント（Windows は Yu Gothic UI）、macOS 13 pt / Windows 11 pt） | プレビューの文字のフォントと大きさです。 |
| 　**不透明度**（既定: 85%。20〜100%） | テキストのプレビューのウインドウ全体（背景と文字）の不透明度です。画像のサムネイルは透明にしません。 |
| **テキストを履歴に残す**（「履歴」グループ。新規。既定: 有効） | オンの間、テキストをコピーしたときに履歴に記録します。オフにすると、テキストのコピーは記録しません（テキストと画像の両方を含むデータは、テキストとして扱います）。 |
| **画像を履歴に残す**（「履歴」グループ。新規。既定: 有効） | オンの間、画像をコピーしたときに履歴に記録します。オフにすると、画像のコピーは記録しません。 |
| **表示順序**（「履歴」グループ。以前の「履歴の表示順」。既定: 新しいもの順） | メニューの「クリップボード履歴」に並べる順序です（新しいもの順 / 古いもの順）。 |
| **履歴数**（「履歴」グループ。1〜100。既定 20） | 保持する履歴の数です。超えた履歴は古いものから順に削除します。同じデータをもう一度コピーした場合は、前の履歴を削除して一番新しい履歴にします。 |
| **現在の履歴数**（「履歴」グループ。以前の「履歴」） | 記録している履歴の数と、「履歴の削除」ボタン（記録している履歴を全て削除します）です。 |

履歴は MiraCursor を終了しても残ります（以前は終了すると消えていました）。履歴は設定とは別のファイルに保存します（macOS は本人だけが読み書きできる権限のファイル、Windows は Windows のデータ保護機能（DPAPI）で暗号化したファイル）。パスワードなどを含むことがあるため、「管理」タブの「設定の保存」で書き出すファイルには含めません。「全て初期設定に戻す」でも削除しません。削除するには「履歴の削除」を押します。「既定値に戻す」は「全般」「プレビュー」「テキストのプレビュー」「履歴」の設定を初期値に戻し、記録している履歴は削除しません。

設定の「キー設定」タブの「クリップボード」グループの「履歴」（以前の「履歴の表示」）のショートカットキー（既定はなし。設定すると）を押すと、マウスカーソルの位置にクリップボード履歴を表示できます（メニューの「クリップボード履歴」と同じ内容です）。

### 定型文

**定型文**を使うと、よく使うテキスト（改行を含められます）や画像を登録しておき、MiraCursor のメニューから選んで使えます。モードではないため、トリガーキーはありません。

1. 設定の「定型文」タブ（サイドバーの「共通」の「クリップボード履歴」の下）の「定型文」グループで、テキストは「テキストを追加」を押して入力欄にテキストを入力します。画像は「画像を追加」を押し、表示された画像の欄をクリックして画像ファイルを選ぶか、画像ファイルを欄にドラッグ＆ドロップします（欄には画像のサムネイルを表示します）。定型文ごとの「削除」で削除でき、一覧の上の「全ての定型文を削除」で全て削除できます（確認が表示されます）。入力した内容はすぐに保存され、MiraCursor を終了しても残ります。
2. メニューの **定型文**（「クリップボード履歴」の下）にマウスポインタを重ねると、登録した定型文が登録した順に番号付きで並びます（テキストは改行をまとめた 1 行の先頭を、「クリップボード履歴」タブの「テキストのプレビュー」の「メニューに表示する文字数」（既定 40 文字）まで、画像は「(Image)」（画像を選んでいない画像の定型文は、選べない「(画像なし)」）。クリップボード履歴と同じく、行ごとに見た目を変えています）。テキストの定型文にマウスポインタを重ねている間は、その内容をプレビュー（テキストで表示するウインドウ）に、画像の定型文ではサムネイルを表示します（クリップボード履歴と同じく、「クリップボード履歴」タブの「プレビュー」の設定に従います）。
3. 定型文を選ぶと、「クリップボード履歴」タブの「全般」の「テキスト選択時の動作」「画像選択時の動作」（クリップボード / 貼り付け / クリップボードと貼り付け）に従って使います。

設定の「キー設定」タブの「クリップボード」グループの「定型文」のショートカットキー（新規。既定は「なし」）を設定すると、キーを押したときにマウスカーソルの位置に定型文の選択メニューを表示できます（メニューの「定型文」と同じ内容です）。

| 設定 | 内容 |
| --- | --- |
| **定型文** | 定型文の一覧です。一番上の「全ての定型文を削除」で全て削除し、一番下の「テキストを追加」「画像を追加」で追加し、「削除」で 1 つずつ削除します。定型文の見出し（macOS は左のつまみ「≡」と「定型文 1」など、Windows は「≡ 定型文 1」など）をドラッグして別の定型文の上にドロップすると、順序を入れ替えられます（メニューの「定型文」の順序も変わります）。 |

「定型文」タブには「定型文」グループだけがあります（「プレビュー」グループは「クリップボード履歴」タブに移動し、「既定値に戻す」ボタンも無くなりました）。登録した定型文は「全て初期設定に戻す」でも削除しません。

### 終了方法

終了方法（以前の「開始/終了方法」）は **トリガーごと** に選べます。トリガーとは、「トリガーキー」「開始するモード」「終了方法」の組のことです。設定の「キー設定」タブの一番上の「トリガーキー」グループの「トリガーの一覧」（以前は「キー設定」タブの「トリガーキー」グループ。その前は「トリガー」タブ・「トリガー」グループの中にありました）には、登録したトリガーが追加した順に 1 行ずつ並んでいて、左に開始するモードを選ぶメニュー、その右に、選んだモードに応じて「⚠ ウインドウ共有時は反映されません」（オレンジ。ペン / ズーム / キーモニタ / スポットライト）または「✓ ウインドウ共有時も反映されます」（緑。カスタムカーソル）の表示（カメラでは表示されません）、トリガーキーのボタン・終了方法（ドロップダウンリスト。macOS はポップアップメニュー、Windows はコンボボックス）・削除のボタン（macOS はマイナスのアイコン、Windows は「✕」のボタン（「メニュー」「キャプチャ」などのキーの割り当てを解除するボタンと同じ形。以前は「削除」の文字のボタン））があります。一覧の下には「トリガーを追加」のボタンがあります（以前あった「ESCキーを2秒間、長押しすると強制終了します」の注意書きはなくなりました）。終了方法は、次の 4 つから選びます（v0.0.5 までは「一時的動作」「トグル動作」の 2 つ）。

| 終了方法 | 動作 |
| --- | --- |
| **キーを離す**（既定。以前の「トリガーキーを離す」。v0.0.5 までは「一時的動作」） | トリガーキーを押している間だけ有効です。そのトリガーのキーを離すか **ESC** キーを押すと終わります。キーモニタのトリガーでは選べません。 |
| **キーの長押し**（新規。以前の「トリガーキーの長押し」） | トリガーキーを長押しすると始まり、キーを離しても続きます。もう一度トリガーキーを長押しすると終わります（同じモードを使っている間なら、別のトリガーで始めた場合でも、終了方法が「キーの長押し」のそのモードのトリガーキーを長押しすると終わります）。**ESC** キーでは終わりません（**ESC** キーの「強制終了の長押し」（既定 1.5 秒）を除く）。 |
| **ESCキー**（v0.0.5 までは「トグル動作」） | トリガーキーを長押しすると始まり、キーを離しても続きます。**ESC** キーを押すと終わります。もう一度長押ししても終わりません（v0.0.5 の「トグル動作」は、もう一度長押ししても **ESC** でも終わりました）。 |
| **メニュー**（新規） | トリガーキーを長押しすると始まり、トリガーキーを離しても **ESC** を押しても終わりません（**ESC** キーの「強制終了の長押し」（既定 1.5 秒）を除く）。終わるには、MiraCursor のメニュー（macOS はメニューバー、Windows はタスクトレイのアイコンのメニュー）で実行中のモード名を選びます。使っている間は、別のモードのトリガーキーを長押ししても切り替わりません（同じトリガーキーをもう一度長押ししても終わりません）。 |

「キーを離す」「ESCキー」の場合は、**ESC** キーでいつでも終了できます（「キーの長押し」「メニュー」の場合は、ESC では終了しません）。

**ESC キーの長押しで強制終了**（新規）**:** どのモードも、トリガーキーとメニューのどちらで始めたかや、終了方法（「キーの長押し」「メニュー」も含む）にかかわらず、**ESC** キーを「強制終了の長押し」の時間（既定 1.5 秒）だけ長押しすると強制的に終了します。終了すると「ESC キーの長押しで、モードを強制的に終了しました」と表示されます。終わり方がわからなくなったときや、メニューを開けないときに使えます（長押しする時間は、設定の「キー設定」タブの「トリガーキー」グループの「強制終了の長押し」で 0.5〜5.0 秒（0.1 秒刻み）の間で変えられます（以前は 2 秒固定）。このことは「開始/終了」グループの説明（ⓘ）にも表示しています）。メニューを開くショートカット（既定: macOS は ⌃⌥M、Windows は Ctrl+Alt+M）でメニューを開いて、実行中のモード名を選んで終わることもできます（[メニューを開くショートカット](#メニューを開くショートカット) を参照）。

同じモードに複数のトリガーキーを割り当てて、キーごとに終了方法を変えることもできます。例えば、次のように登録すると、ペンを「押している間だけ」使うことも、「キーを離しても続けて」使うこともできます。

| トリガーキー（Windows） | トリガーキー（macOS） | モード | 終了方法 |
| --- | --- | --- | --- |
| 右 Alt | 右 Option | ペン | キーを離す |
| 右 Ctrl | 右 Control | ペン | ESCキー |

（この例のように登録する場合は、既定のトリガー（ペン = 左 Shift + 左 Ctrl（macOS は左 Shift + 左 Control））のキーを右 Alt（macOS は右 Option）に変えてから、右 Ctrl（macOS は右 Control）・ESCキーのトリガーを追加してください。同じキーは複数のトリガーに割り当てられません。）

- **既定値:** 既定のトリガーは終了方法「ESCキー」（以前は「キーを離す」）、「トリガーを追加」で追加したトリガー（キーは「なし」）は「ESCキー」です（v0.0.5 までは「一時的動作」）。「管理」タブの「全て初期設定に戻す」や、「キー設定」タブの「トリガーキー」グループの「既定値に戻す」を実行したときも、既定のトリガー（ペン = 左 Shift + 左 Ctrl（macOS は左 Shift + 左 Control）・「ESCキー」の 1 つだけ）に戻ります。すでに設定している終了方法は、アップデートしてもそのままです（v0.0.5 の「一時的動作」は「キーを離す」、「トグル動作」は「ESCキー」になります。「ESCキー」はもう一度長押ししても終わらないため、長押しで終わりたい場合は「キーの長押し」に変えてください）。
- **macOS の注意表示:** 終了方法が「キーを離す」で、クリックが背後のアプリに届くモード（ペン以外。ペンはクリックを MiraCursor が受け取ります）のトリガーには、トリガーキーに含む修飾キーに応じて、そのトリガーの行の下に次の注意が表示されます。
  - Option を含む場合: 「Option キーを押したまま他のアプリのウインドウをクリックすると、それまで使っていたアプリが隠れます（macOS の機能）。クリックする場合は終了方法を「キーを離す」以外にすることをおすすめします。」
  - Control を含む場合: 「Control キーを押したままクリックすると、副ボタンのクリック（右クリック）として扱われます（macOS の機能）。左クリックする場合は終了方法を「キーを離す」以外にすることをおすすめします。」
  - 既定の設定（ペン = 左 Shift + 左 Control・キーを離す）では、注意は表示されません。以前の既定のトリガーにあったカスタムカーソル（右 Option・キーを離す）のように、Option を含むトリガーには Option の注意が表示されます。キーを押したまま他のアプリのウインドウをクリックすると、それまで使っていたアプリが隠れるため、カスタムカーソルの表示中に他のアプリのウインドウをクリックしたい場合は終了方法を「キーを離す」以外にしてください（ペン（右 Control）はクリックを MiraCursor が受け取るため、注意は表示されません）。
- **まとめて変更:** 「キー設定」タブの「トリガーキー」グループ（以前の「トリガー」グループ）にある「終了方法の一括変更」（以前の「全トリガーを一括変更」）の「キーを離す」「キーの長押し」「ESCキー」「メニュー」ボタン（以前の「トリガーキーを離す」「トリガーキーの長押し」。v0.0.5 までは「一時的」「トグル」）で、すべてのトリガーの終了方法を一度に変えられます（トリガーが 1 つもないときは押せません。「キーを離す」「キーの長押し」を選んでも、トリガーキーが「なし」のトリガーは「ESCキー」になります。キーモニタのトリガーは、「キーを離す」を選ぶと「ESCキー」になります）。
- **以前の設定:** 以前のバージョンでモードごとに設定していたトリガーキーと開始/終了方法（さらに以前の全モード共通の開始/終了方法）は、そのままトリガー（キーと終了方法）として引き継がれます。
- **メニューでの確認:** メニューバー / タスクトレイのアイコンのメニューには、モードごとに 1 行で、そのモードのすべてのトリガーのキーと終了方法が表示されます（例: macOS は「ペン: 右 Control（キーを離す）、右 Option（ESCキー）」、Windows は「ペン: 右 Ctrl（キーを離す）、右 Alt（ESCキー）」。以前は「（トリガーキーを離す）」「（トリガーキーの長押し）」、v0.0.5 までは「（一時的）」「（トグル）」と表示されていました。キーを設定したトリガーがないモードは「未設定」と表示されます）。

### トリガーキー

トリガーキーには、**修飾キー**（Ctrl / Alt / Shift / Windows、macOS では Control / Option / Shift / Command / fn）を使います。左右のキーは区別され、複数のキーを組み合わせることもできます（例: 「左 Shift + 左 Ctrl」）。

既定では、ペンのトリガー 1 つだけが登録されています（終了方法は「キーを離す」。以前はカスタムカーソル（右 Alt、macOS は右 Option）のトリガーもありました）。

| モード | 既定のトリガーキー（Windows） | 既定のトリガーキー（macOS） |
| --- | --- | --- |
| カスタムカーソル | なし（以前は右 Alt） | なし（以前は右 Option） |
| ペン | 左 Shift + 左 Ctrl（以前は右 Ctrl） | 左 Shift + 左 Control（以前は右 Control） |
| スポットライト | なし | なし |
| ズーム | なし | なし |
| キーモニタ | なし | なし |

カスタムカーソル・スポットライト・ズーム・キーモニタには、既定ではトリガーがありません。使う場合は、設定の「キー設定」タブの「トリガーキー」グループの「トリガーを追加」でトリガーを追加し、モードとキーを設定してください。

> 既定のトリガーキーは、新しくインストールしたとき、「管理」タブの「全て初期設定に戻す」を実行したとき、「キー設定」タブの「トリガーキー」グループの「既定値に戻す」を押したときに使われます。すでに設定しているトリガーキーと終了方法は、アップデートしてもトリガーとしてそのまま引き継がれます（以前のバージョンの既定値のまま使っている場合も変わりません。保存しているトリガーの一覧も、既定のトリガーが変わってもそのままです（カスタムカーソルのトリガーも残ります）。新しい既定値にしたいときは「既定値に戻す」を押してください）。

- **キーの登録方法:** 設定の「キー設定」タブの「トリガーキー」グループで、トリガーの行のモードのメニューの右にあるキーの欄（キーが未設定なら薄い文字で「未設定」と表示）をクリックし、トリガーにしたいキーを実際に押して離します（記録中は欄の枠が強調色になります）。欄の右の「✕」（キーが設定されているときだけ表示）を押すと、キーを未設定にできます。
- **トリガーキーを「なし」にする:** キーのボタンをクリックした後（記録中）に **ESC** キーを押すと、トリガーキーは「なし」になります（v0.0.5 までは記録の取り消し）。トリガーキーが「なし」のトリガーのモードは、メニューからだけ始められます。このとき終了方法は「ESCキー」か「メニュー」だけ選べます（リストに「キーを離す」「キーの長押し」が表示されません）。「なし」にしたときに「キーを離す」「キーの長押し」だった場合は「ESCキー」に変わります。読み込んだ設定でキーが「なし」かつ「キーを離す」「キーの長押し」の場合も「ESCキー」になります。ペンの直線モード・キャプチャのキーの記録では、ESC は従来どおり記録の取り消しです。
- **トリガーの追加と削除:** 一覧の下の「トリガーを追加」で、キーが「なし」・終了方法「ESCキー」（v0.0.5 までは「一時的動作」）のトリガーを追加します（モードは、まだトリガーがないモードのうち先頭のもの。すべてのモードにトリガーがある場合はペン）。使わなくなったトリガーは、行の右端の削除のボタン（macOS はマイナスのアイコン、Windows は「✕」のボタン（「メニュー」「キャプチャ」などのキーの割り当てを解除するボタンと同じ形。以前は「削除」の文字のボタン））で削除します。トリガーが 1 つもないときは「トリガーがありません。「トリガーを追加」で追加してください。」と表示されます。
- **ウインドウ共有時の表示:** 「トリガーキー」の一覧の各行には、その行で選んだモードに応じて、トリガーキーのボタンの左（Windows は行の下。以前はボタンの左でしたが、行が設定ウインドウの幅に収まらず、右端の削除のボタンが見切れていたため移しました）に、ペン / スポットライト / ズーム / キーモニタでは「⚠ ウインドウ共有時は反映されません」、カスタムカーソルでは「✓ ウインドウ共有時も反映されます」が表示されます（カメラでは表示されません。行のモードを変えると表示も変わります）。以前の「トリガー」タブの「モード」のグループ（電球のアイコン・モード名・モードの説明）はなくなりました。
- **重複の禁止:** 同じキー（組み合わせ）を、複数のトリガーに割り当てることはできません（「X は「<モード>」のトリガーキーで使用中のため設定できません。」と表示されます）。
- **ペンのトリガーの制限:** ペンのトリガーには、ペンの直線モードの「開始キー」と「撮影キー」に含まれるキーは使えません。キーを記録するときも、トリガーのモードをペンに変えるときも同じで、変更できない場合は行の下にエラーが表示されます。
- **ショートカット操作との区別:** 長押しの途中で他のキーやマウスボタンを押した場合は、通常のショートカット操作（コピーなど）とみなします。この場合、強調表示は始まりません。
- **既定値に戻す:** 「キー設定」タブの「トリガーキー」グループの一番下の「既定値に戻す」で、開始の長押し（以前の「長押し時間」）・強制終了の長押しとトリガーの一覧（上の表の既定のトリガー。すべて「キーを離す」）を初期値に戻せます。このとき、ペンの直線モードの開始キー・撮影キーが、ペンのトリガーキーに含まれるキーを使っている場合は「なし」になります。

### カスタムカーソル

マウスカーソルのアイコンを変更します

- **トリガーキー:** 既定のトリガーはありません（以前は右 Alt（macOS は右 Option））。使う場合は、設定の「キー設定」タブの「トリガーキー」グループの「トリガーを追加」で登録してください。
- **画面共有で見える:** 別のウインドウに描くのではなく、システムのマウスカーソル自体を変えます。そのため、Slack・Webex・Teams・Zoom などで **特定のアプリのウインドウだけを共有している場合でも、相手に見えます**。
- **表示するアイコン:** 次の 4 つのグループから選べます（4 つのグループを通して、必ず 1 つだけ選ばれます）。設定画面では上から ハイライトカーソル / ズームカーソル / シンプルカーソル / オリジナルカーソル の順に並んでいます。
  - **ハイライトカーソル**（既定。以前の既定は通常のカーソル）: 通常のカーソルの周りに半透明の色を重ねたカーソルです（下の「ハイライトカーソル」を参照）。
  - **ズームカーソル**: マウスカーソルの位置を拡大して表示する拡大鏡のカーソルです（下の「ズームカーソル」を参照）。
  - **シンプルカーソル**（色を設定できる）: 通常のカーソル / 指差し / 斜めの指 / 指差し棒 / マウス / いいね！ / 流星 / 位置情報ピン / ハート / スイカ。画像の下に名前を書いたタイルを、1 行に 5 つまで並べています（上の段: 通常のカーソル〜マウス、下の段: いいね！〜スイカ。macOS・Windows とも、ウインドウの幅によらず同じ並びです）。
  - **オリジナルカーソル**（色は設定できない）: 任意の画像1 / 任意の画像2 / 任意の画像3（以前の「カラーカーソル」の名前を変えたものです。スイカはシンプルカーソルに移りました）
  - シンプルカーソルの「虫眼鏡」「懐中電灯」「メガホン」「吹き出し」「足跡」「カーブした矢印」「魔法のステッキ」「円形」はなくなりました。選んでいた場合は、既定の通常のカーソルになります。
  - 以前の「四角（正方形）」と「パルスカーソル」はなくなりました。これらや不明な画像を選んでいた場合は、既定の通常のカーソルになります。以前の「流れ星」はなくなり、選んでいた場合は、ぐるっと円を描くように尾を引く「流星」になります。パルスカーソルの代わりに、「表示」の「アイコンをアニメーションする」で、どのアイコンもアニメーションできます。
- **ハイライトカーソル:** 通常のカーソル（黒い矢印）の周りに半透明の色の円を重ねて、マウスカーソルとして表示します（以前のライトモードの動作モード「ハイライト」を移したものです）。
  - 画面に重ねて描く（オーバーレイ）のではなく、色の円を含めた画像をシステムのマウスカーソルそのものにするため、オンライン会議で **特定のウインドウだけを共有している場合でも、ハイライトが相手に見えます**（会議アプリが大きなカーソルを縮小・切り取る場合は、その表示になります）。
  - 円の中心（矢印の先端）がクリックする位置です。
  - **色:** 既定は黄色（`#FFCC00`）
  - **不透明度:** 10〜100%（既定 40%）
  - **半径:** 10〜300（既定 50。macOS は pt、Windows は 96 DPI 換算の px）
  - **ぼかし:** 0〜100%（既定 30%）
  - 以前のライトモードの「ハイライト」の設定値は、そのまま引き継がれます。「表示」の大きさ・アニメーションは使いません（ハイライトカーソルを選んでいる間は変更できません）。
- **ズームカーソル:** マウスカーソルの位置を拡大した拡大鏡を、マウスカーソルとして表示します。
  - 画面に重ねて描く（オーバーレイ）のではなく、システムのマウスカーソルそのものを書き換え続けるため、オンライン会議で **特定のウインドウだけを共有している場合でも、拡大した内容が相手に見えます**。
  - クリックする位置は拡大の中心です。
  - 「ズームカーソル」の選択の下に、「ズーム」と「十字線」の 2 つのサブグループがあります。
  - **ズーム / サイズ:** 拡大鏡の一辺の長さです（64〜600、8 刻み、既定 160。macOS は pt、Windows は 96 DPI 換算の px）。
  - **ズーム / 形:** 「四角」（既定）/「丸」から選べます（ラジオボタン）。
  - **ズーム / 拡大率:** 1.5〜20.0 倍（0.5 刻み、既定 2.0 倍）。
  - **十字線 / 種類:** 拡大鏡の中に表示する、中心を通る十字線の種類です（以前の「十字線」）。なし / 実線 / 破線（既定）/ 点線 / 一点鎖線 / 二重線 / 二重破線 / 二重点線 から選べます。クリックする位置（拡大の中心）が分かりやすくなります。
  - **十字線 / 太さ:** 1〜10（既定 1。ズームモードの十字線と同じ）。
  - **十字線 / 不透明度:** 10〜100%（既定 80%。ズームモードの十字線と同じ）。
  - **十字線 / 色:** 既定は、ズームモードの十字線の色と同じグレー。
  - 種類が「なし」のときは、太さ・不透明度・色は変更できません。「表示」の大きさ・アニメーションは使いません（ズームカーソルを選んでいる間は変更できません）。
  - macOS では、画面の内容を読むため「画面収録」の権限が必要です（macOS 14 以降。それより前の macOS では通常のカーソルを表示します）。
  - 拡大鏡にはカーソルの周りの画面がそのまま映るため、ウインドウの端の近くでは、共有していない隣のウインドウや通知なども拡大して相手に映ることがあります。
- **指差し棒:** 先端が左上を向いた棒です。先端がクリックする位置です。単色（モノトーン）のアイコンなので、色を変えられます。
- **スイカ:** 三角形に切ったスイカです。左上を向いた頂点がクリックする位置です。単色（モノトーン）のアイコンなので、ほかのシンプルカーソルと同じく色を変えられます。
- **色:** シンプルカーソルは単色（モノトーン）のアイコンで、シンプルカーソルのグループの中にある「色」で色を変えられます（既定は黒）。
  - 黒・白・グレー・赤・オレンジ・黄・緑・水色・青・紫・ピンクから選べるほか、好きな色も指定できます（macOS: カラーピッカー、Windows: 「その他の色...」ボタン）。
  - 縁取りは、選んだ色に合わせて自動で白か黒になるため、どんな背景の上でも見えます。
  - オリジナルカーソル（任意の画像）は色を変えられません。
- **任意の画像:** 好きな画像を 3 つまで登録できます（任意の画像1〜3）。オリジナルカーソルのグループの中に、任意の画像ごとの行が縦に並んでいます。
  - **行の並び:** 左から、使う画像を選ぶボタン（ラジオボタンのように 1 つだけ選べます。画像のプレビューと名前が表示されます）、「クリック位置」、「画像を選択…」、「削除」の順です。画像が登録されていない枠を選ぶと、画像を選ぶダイアログが開きます。
  - **登録のしかた:** 「画像を選択…」で画像を選ぶか、画像ファイルを行にドラッグ＆ドロップします。
  - macOS: PNG / JPEG / HEIC / GIF / TIFF / SVG / PDF など
  - Windows: PNG / JPEG / BMP / GIF / TIFF / ICO
  - 選んだ画像は PNG に変換して保存します（macOS: `~/Library/Application Support/MiraCursor/cursor-image-1.png`〜`cursor-image-3.png`、Windows: `%APPDATA%\MiraCursor\cursor-image-1.png`〜`cursor-image-3.png`）。大きな画像は、長い辺が 1024 ピクセルになるように縮小します。
  - **削除:** 「画像を選択…」の右にある「削除」ボタンで、登録した画像を削除できます。その画像をカーソルに選んでいた場合は、既定のハイライトカーソルに戻ります。画像が登録されていないときは押せません。
  - **クリック位置:** 画像のどこでクリックするかを「左上」（既定）/「右上」/「左下」/「右下」/「中央」から選べます。縦横比を保って表示した画像の角または中央です。
  - 「管理」タブの「全て初期設定に戻す」を実行すると、登録した画像もすべて削除されます。
  - 以前のバージョンで登録した画像（`cursor-image.png`）は、自動で「任意の画像1」に引き継がれます。
  - 以前の、任意の画像1〜3 を横に並べた一覧はなくなりました。画像は各行の左のボタンで選びます。
- **クリックする位置:** 通常のカーソル・指差し・斜めの指・指差し棒は先端、流星は左上の星の中心、位置情報ピンは下の先端、マウス・いいね！・ハートは画像の中心、ハイライトカーソルは円の中心（矢印の先端）、ズームカーソルは拡大の中心、スイカは左上の頂点、任意の画像は「クリック位置」で選んだ位置です。
- **表示:** 「表示」の設定では、アイコンのサイズとアニメーションを設定できます。
  - **表示するアイコンのサイズ:** 15〜512（8 刻み（15, 16, 24, … 512）、既定 128。macOS は pt、Windows は 96 DPI 換算の px）。macOS では、アクセシビリティの「ポインタのサイズ」を大きくしていても、指定したサイズで表示します。
  - **アニメーションの種類**（既定: なし）**:** シンプルカーソル・オリジナルカーソルのどちらにも使えます。以前の「アイコンをアニメーションする」をオンにしていた場合は、「拡大縮小」になります。
    - **なし:** アニメーションしません。
    - **拡大縮小:** クリックする位置を中心に、ゆっくり大きくなったり小さくなったりします（設定したサイズの 55〜100% の間）。
    - **ゆらゆら:** クリックする位置を支点に、振り子のように左右に揺れます（±20 度）。
    - **明滅:** 透明度が変わり、薄くなったり濃くなったりします（不透明度 20〜100% の間）。
    - 以前の「左回転」「右回転」はなくなりました。選んでいた場合は「なし」になります。
    - クリックする位置は、どのアニメーションでも動きません。Windows でアニメーションする場合は、一辺 256 ピクセルまでで表示します（ゆらゆらでは、揺れても収まるように広げた画像が 256 ピクセルに収まる大きさになります）。
  - **アニメーションの早さ:** 1 周期の時間です。短いほど早く動きます（0.4〜4.0 秒、0.1 刻み、既定 1.6 秒）。「なし」のときは変更できません。
- **残像 / 波紋:** 残像と波紋は、「表示」とは別の「残像」「波紋」の 2 つのグループで設定します。どちらのグループにも「ウインドウ共有時は反映されません」という注意が表示されます。
  - **マウスカーソル移動時に残像を表示する**（既定: オフ）**:** カーソルが通った位置に、そのときのカーソルの形で残像を表示します。不透明度 50% から始まり、「残像を残す時間」をかけて薄くなって消えます。
    - **残像を残す時間:** 0.1〜2.0 秒（0.1 刻み、既定 0.5 秒）
    - **残像の数:** 同時に表示する残像の数です（1〜30、既定 8）。残像は「残像を残す時間」の中で等間隔に残します（間隔は「残す時間 ÷ 残像の数」。最大で 1 秒に 60 個）。数を超えると、古い残像から消えます。
  - **マウスクリック時に波紋を表示する**（既定: オフ）**:** クリックした位置から、波紋が円形に広がって消えます。クリックは、そのまま背後のアプリに届きます。
    - **波紋の色:** 既定は黄色（`#FFCC00`）
    - **波紋の広がる早さ:** 波紋が広がりきるまでの時間です。短いほど早く広がります（0.2〜2.0 秒、0.1 刻み、既定 0.4 秒）。
    - **波紋の大きさ:** 広がりきったときの半径です（20〜300、10 刻み、既定 60。macOS は pt、Windows は 96 DPI 換算の px）。
    - **波紋の透明度:** 0〜90%（5% 刻み、既定 20%）
  - 残像と波紋は、ペンやスポットライトと同じく画面に重ねて描くため、特定のアプリのウインドウだけを共有している場合は相手に映りません（画面全体を共有すれば映ります）。カーソルそのものは、ウインドウだけの共有でも相手に見えます。
- **ちらつかない:** マウスを動かしても、カーソルが OS の通常のカーソルに戻ってちらつくことはありません。
- **設定の反映:** 設定の変更は、次にモードを開始したときから反映されます。
- **注意:** 独自のカーソル画像を使っているアプリの上では、そのアプリのカーソルが表示されることがあります。
- **以前の設定:** 以前の「マウスカーソル」モードで使っていた設定（トリガーキーを含む）は、そのまま引き継がれます。

### ペン

画面に線を描けます。

- **トリガーキー:** 既定のトリガーは左 Shift + 左 Ctrl（macOS は左 Shift + 左 Control。以前は右 Ctrl / 右 Control）で、終了方法は「ESCキー」です（以前は「キーを離す」）。「キー割り当て」の「キャプチャ」の既定値は右 Shift です（以前は未設定）。以前に保存した設定はそのまま使います。
- **「左クリック」「右クリック」の並び（変更）:** 種類・不透明度・色・太さ・終点の順にしました（以前は 種類・太さ・不透明度・色・終点）。
- **左右のボタン:** 設定の「左クリック」「右クリック」（以前の「左クリック時の表示」「右クリック時の表示」）で、ボタンごとに「種類・不透明度・色・太さ・終点」（以前の「線の種類」「線の太さ」「線の不透明度」「線の色」。設定画面ではこの順）を設定できます。
  - 種類は、実線 / 破線 / 点線 / 一点鎖線 / 二重線（新規）/ 二重破線 / 二重点線 / 消しゴムから選べます。
  - 「終点」（「色」の下）は、なし（既定）/ シンプル（塗りつぶした三角の矢じり）/ オープン（線の太さの 2 本の線で描く開いた矢じり）/ 鋭い（後ろがくぼんだ鋭い矢じり）/ ひし形（終わりの点を中心に塗りつぶしたひし形）/ 円形（終わりの点を中心に塗りつぶした円） から選べます（設定画面では、名前とその形で終わる短い線の表示例が並びます）。描いた線の終わりに、選んだ形を線の色で描きます（矢じりは線の向きを向きます。大きさは太さの 3 倍。最小 12）。種類が消しゴムのときは使えません。動かさずにクリックしただけのときは描きません。
- **直線モード:** 線の角度が 45 度単位（水平・垂直・斜め）になり、まっすぐな線を描けます。
  - 直線モードになるのは、「キー割り当て」グループ（新規。「右クリック」の下）の **直線モード** のキー（以前は「直線モード」グループの「キー」）を押している間だけです（キーが「なし」（既定）なら直線モードは無効。以前の「条件」（常に有効 / キーを押している間）は廃止しました）。
  - 直線モードの「開始キー」（以前の「直線モードの開始キー」）には、他のモードのトリガーキーと同じキーも使えます（ペンモードの間だけ使うキーのため、区別できます）。ただし、ペンのトリガーキーに含まれるキー（例: トリガーキーが「左 Shift + 左 Control」なら、左 Shift や左 Control を含むキー。ペンにトリガーが複数ある場合は、そのすべてのトリガーキーに含まれるキー）や、撮影キーと同じキーは使えません。
- **線を消すには:** モードを終えると、描いた線はすべて消えます。
- **クリックの扱い:** ペンモードの間、マウスのクリックは MiraCursor が受け取ります（背後のアプリはクリックされません）。
- **カーソルの形:** ペンモードの間、マウスカーソルは左右ボタンの色の 2 色で塗ったペンのアイコンになります（設定で無効にできます）。
  - **カーソルの大きさ:** ペンのアイコンの大きさです（16〜128、4 刻み、既定 48。macOS は pt、Windows は 96 DPI 換算の px）。「実行中はアイコンを変更する」がオンのときだけ変更でき、次にモードを開始したときから反映されます。
- **消しゴム:** 「左クリック」「右クリック」の「種類」で「消しゴム」を選ぶと、そのボタンでドラッグした跡の線を消せます。
  - 消す幅は、そのボタンの「太さ」です（太さは線・消しゴムとも 1〜100、既定 10（以前は 8）。macOS は pt、Windows は 96 DPI 換算の px。以前は 1〜40）。「不透明度」「色」は使わないため、変更できなくなります。
  - 左クリックと右クリックの両方を消しゴムにすることはできません。
  - 消しゴムでドラッグしている間は、マウスカーソルが「太さ」に合わせた消しゴムのアイコン（消す範囲の円と消しゴムの絵）になります。
  - 「実行中はアイコンを変更する」が有効な場合、ふだんのアイコンは、右クリックが消しゴムなら「左側に 1 色のペン（左クリックの色）・右側に消しゴム」、左クリックが消しゴムなら「左側に消しゴム・右側に 1 色のペン（右クリックの色）」になります（どちらもペン先がクリックする位置）。
- **キャプチャ:** ペンで描いた内容を含めて画面をキャプチャできます。キーは、設定の「ペン」タブの「キー割り当て」グループ（新規）の **キャプチャ**（以前は「キャプチャ」グループの「キー」。既定: なし）で設定します。
  - **キャプチャの流れ（変更）:** ペンモードの間にキャプチャのキーを押すと、キャプチャモードと同じ「キャプチャ対象の選択ウインドウ」を開きます。選択ウインドウで撮影対象（選択範囲 / ウインドウ / デスクトップ / 文字/QRコード読み取り など）や遅延時間などを選び、ドラッグ・クリックすると、ペンで描いた内容を含めてキャプチャします。選択ウインドウを表示している間は、ペンモードのトリガーキーやキャプチャのキーから指を離しても、選択ウインドウは閉じません（終了方法が「キーを離す」のトリガーでも、ペンモードは終了しません）。キャプチャした後は、「キャプチャ」タブの「全般」の **連続してキャプチャ** に従います（有効なら選択ウインドウを表示したまま、ペンモードを続けて何度でもキャプチャできます。無効ならペンモードを終了します。キャプチャする場合、描いた線はキャプチャが終わるまで表示したままです）。選択ウインドウの「閉じる」で取り消した場合（選んでいる間にもう一度キャプチャのキーを押した場合や、ESC キーの場合も）は、ペンモードを終了します。
  - 以前の「キャプチャ」グループの **対象** の設定は廃止しました（選択ウインドウで選びます）。
  - **タイミング:** 「キャプチャしない」/「ペンモードの終了時」（描いた線が消える前にキャプチャします）/「撮影キーを押した時」（既定。ペンモードの間に「撮影キー」を押すとキャプチャします。ペンモードは続きます）から選びます。
  - **撮影キー:** 「撮影キーを押した時」のときに使うキーです（既定: 右 Alt、macOS は右 Option）。トリガーキーと同じく、ボタンをクリックしてから実際にキーを押して記録します。他のモードのトリガーキーと同じキーも使えます（ペンモードの間だけ使うキーのため、区別できます）。ただし、ペンのトリガーキー（ペンにトリガーが複数ある場合はそのすべて）に含まれるキーや、直線モードの開始キーと同じキーは使えません。ペンのタブの「既定値に戻す」を押したときに、既定のキーがペンのトリガーキーに含まれるキーと重なる場合や、直線モードの開始キーと同じ場合は「なし」になります。
    - macOS・Windows とも、修飾キー（Shift / Control（Ctrl）/ Option（Alt）/ Command / fn / Windows）の組み合わせだけを使えます。F キーなどの修飾キー以外のキーは、macOS ではキー入力を止められず前面のアプリ（プレゼンテーションのアプリなど）にも入力されてしまうため、両方で使えないようにそろえています。
  - **撮影条件:** 「常に撮影する」（既定）/「ペンを利用した場合のみ」から選びます。「ペンを利用した場合のみ」の場合、ペンで何も描いていなければ撮影しません（撮影キーを押した場合は、撮影しなかったことをメッセージで知らせます）。
  - **撮影までの遅延時間:** 0〜10 秒（1 秒刻み、既定 0 秒＝すぐにキャプチャ）。0 秒以外のときは、画面の中央にカウントダウンを表示してからキャプチャします。カウントダウンはキャプチャ画像には写りません。
  - **撮影音を鳴らす**（既定: オン）**:** 撮影するときに、カメラのシャッター音を鳴らします。遅延時間がある場合は、画面の数字がカウントダウンするのに合わせて「かちっ」「かちっ」「かちっ」とカウントダウン音を鳴らし、遅延時間が終わってからシャッター音を鳴らします。
  - **撮影対象:** 「アクティブなデスクトップ」（既定。マウスカーソルのあるディスプレイ）/「全てのデスクトップ」（マルチモニタのすべてのディスプレイを、配置どおりに 1 枚の画像にします）から選びます。
  - **マウスカーソルをキャプチャする**（既定: オフ）**:** オンにすると、キャプチャ画像にマウスカーソルも写します。ペンモードの間はカーソルがペンのアイコンになっていますが、画像には OS 標準の矢印のカーソルを、撮影したときのマウスカーソルの位置に描き込みます。
  - **保存先:** 設定の「キャプチャ」タブの「キャプチャ後の動作」（「ファイルに保存」（既定）/「クリップボードにコピー」/「ファイルとクリップボード」/「MiraPaint」。キャプチャモード・ショートカットキーと共通）に従います。ファイルに保存する場合は、あらかじめ選んだフォルダ（既定はユーザーのデスクトップ。「開く」ボタンで、macOS は Finder、Windows はエクスプローラーで開けます）に `Image-yyyymmdd-HHMMSS.<拡張子>`（例: `Image-20261012-105120.png`）の名前で保存します（同じ名前のファイルがある場合は `-2` などを付けます。以前は `Capture-yyyymmdd-HHMMSS`）。
  - **画像ファイルの拡張子:** PNG（既定）/ WebP（可逆圧縮）/ JPEG から選びます。保存先が「クリップボードにコピー」の場合は使いません。
  - **MiraPaint:** 保存先が「MiraPaint」の場合は、撮影した画像を MiraCursor の MiraPaint で開きます（撮影キーで撮影した場合は、ペンモードを自動的に終了します。サムネイルは表示しません）。ボタンはすべて文字の無いアイコンで、マウスポインタを重ねると名前を表示します。選んでいるツールの設定は画像の上に浮かぶ設定パネルに表示し、見出し（ツール名）の右の情報ボタン（丸の中の i）にマウスポインタを重ねると、そのツールの説明と操作の方法をすぐに表示します（以前はパネルの下に表示していた操作の説明を、情報ボタンに移しました。説明は、見出しにツール名があるためツール名を繰り返さない文です。例: スポットライトは「ドラッグした範囲以外を暗くして、範囲だけを明るく見せます。続けて置いたスポットライトは、「暗さ」を変えるとまとめて変わります。」。ツールバーのボタンのツールチップは従来どおり「ツール名（説明）」です）。
    - **ツールバーの並び:** 左から「表示を縮小・表示倍率の一覧・表示を拡大・ウインドウに合わせる・グリッドの表示・テキストブラー・文字/QRコード読み取り」（表示）「新規作成・ファイルを開く・クリップボードから開く・カメラから取り込み」（開く）「上書き保存・ファイル名を指定して保存・指定ディレクトリへ保存・クリップボードへ保存」（保存）「ファイルからレイヤーに追加・クリップボードからレイヤーに追加」（レイヤー）「選択」（選択）「ペン・蛍光ペン・直線・折れ線・矢印・四角・丸・スプレー・テキスト・番号・ルーペ」（描画）「スポットライト・モザイク・フェイドアウト・画質調整」（加工。スポットライトはモザイクより使うことが多いため、以前のモザイクの後ろから前に移しました）「サイズ変更・クロップ・回転・範囲選択・魔法の杖・背景」（変形）のグループの順に並んでいます（「サイズ変更」のボタンを「クロップ」の左に戻しました。以前は独立した「画像サイズ」のボタンがあり、その後「クロップ」に統合していました。グループの間には細い区切り線があります。「テキストブラー」と「文字/QRコード読み取り」は以前は「加工」のグループに、「変形」のグループは以前は「保存」の次にありました。「選択」のグループは新しく作ったもので、以前は「選択」・「範囲選択」・「魔法の杖」は「描画」のグループにありました。「範囲選択」は、その後「選択」のグループを経て「変形」のグループの「回転」の右に移り、その後「変形」のグループの先頭に移り、今は「回転」の右にあります。「魔法の杖」も「選択」のグループから「変形」のグループに移り、今は「範囲選択」の右にあります。「選択」のグループは「選択」ツールだけになりました）。「上書き保存」は、Windows の「プログラムから開く」や macOS のサービスメニューから既存のファイルを開いて編集した場合だけ使え、開いたファイルにその拡張子の形式（PNG / WebP / JPEG）で保存します。
    - **Tab キーでツールを切り替え（新規）:** **Tab** を押すと、選んでいるツールの次のツールを、**Shift + Tab** を押すと前のツールを選びます（ツールバーの並び順。最後のツールの次は最初のツールに戻ります）。テキストを入力している間・入力欄（表示倍率・数値など）で入力している間と、マウスのボタンを押している間は、通常の Tab キーの動作になります。
    - **変形**（以前の「全体」）**:** サイズ変更（画像の拡大・縮小。画像の端・角のつまみをドラッグするか、画像の上をドラッグすると（右下の角を動かします）、画像の大きさを変えます。設定パネル（見出しは「サイズ変更」）で幅・高さ（px）か倍率（%）を入力して ✓（または Return / Enter）を押しても変えられます（「縦横比を保持」をオンにすると、幅・高さの一方を変えたときにもう一方を合わせます。この設定は数値の入力だけに使い、つまみのドラッグでは Shift キーで縦横比を保ちます（以前はドラッグも「縦横比を保持」に従いました）。↺ で入力した値を取り消します。Windows は、入力した大きさを画像の上に破線の枠で表示します。ハンドルをドラッグしている間は、クロップと同じく新しい大きさの外側を暗く、内側を明るく表示します（Windows は入力した大きさのプレビュー中も同じ。以前は枠だけでした））。以前は独立した「画像サイズ」のボタンで、その後「クロップ」に統合していましたが、再び独立したツールになりました）/ クロップ（画像の切り抜き。画像の端・角のつまみをドラッグして範囲を調整するか、画像の上をドラッグして新しい範囲を決めると切り抜きます。以前は設定パネルで幅・高さ・倍率を入力して画像の大きさも変えられましたが、今は「サイズ変更」を使います）/ 回転（画像の中心に表示される回転のハンドル（中心の支点・腕・つまみ）をドラッグすると、ドラッグした角度に画像が回転します。**Shift** を押しながらドラッグすると 15° 刻み、ドラッグ中は角度を表示し、**Esc** で取り消せます。画像の大きさは変わらず、はみ出した部分は削除され、空いた四隅は透明になります。設定パネルの右へ / 左へ 90 度回転と、左右反転 / 上下反転も使えます）/ 範囲選択 / 魔法の杖（以前の「部分削除」。クリックした部分とつながっている似た色の部分を選択します）/ 背景 / 表示の拡大・縮小（ウインドウに合わせる・100% で表示も選べます）。変形のツールの設定も、設定パネルで設定ごとに枠線で囲んだグループに並びます（例えば範囲選択は「選び方」「編集」、回転は「回転」「反転」。グループが 1 つだけのクロップ・背景などはタイトル無しの枠）

    - **クロップ:** 範囲を決めると、確認せずにすぐに切り抜きます（「元に戻す」で戻せます）。以前の「クロップ時に確認する」（「サイズ変更前に確認する」）の設定は廃止しました。
  - **サムネイル画像**（設定の「キャプチャ」タブの「プレビュー」グループ。新設）の **表示位置**（以前の「サムネイル画像の表示位置」）・**表示時間**（新規。1〜10 秒、既定 3 秒）**:** キャプチャすると、アクティブなデスクトップ（マウスカーソルのあるディスプレイ。以前はマウスカーソルのあるウインドウ）の指定した位置（左上 / 上 / 右上 / 左 / 右 / 左下 / 下 / 右下（既定）。以前は四隅だけ。「上」「下」はウインドウの左右中央、「左」「右」は上下中央）に、撮影した画像のサムネイルを約 3 秒間表示します。サムネイルも、次のキャプチャには写りません。同じグループの **サイズ**（新規。サムネイルの長い辺の大きさ。120〜480・20 刻み・既定 240。macOS は pt、Windows は 96 DPI 換算の px）で大きさを変えられます。クリップボード履歴・定型文の画像のサムネイルは、このサイズ・表示位置を使いません（「クリップボード履歴」タブの「プレビュー」の「位置」「幅」「高さ」に従います。以前はこのサイズ・表示位置に従っていました）。
  - **macOS の場合:** 「画面収録」の権限が必要です。また、macOS 14 Sonoma 以降でのみ使えます。

### スポットライト

画面全体を薄暗くして、マウスカーソルの周りだけを明るく表示します。以前の「ライト」モードの名前を変えたものです（さらに以前も「スポットライト」でした）。

- **トリガーキー:** 既定ではトリガーがありません。使う場合は、設定の「キー設定」タブの「トリガーキー」グループの「トリガーを追加」でトリガーを追加してください。
- **設定（「全般」グループ。以前の「スポットライト」グループ）:**
  - **色（背景の色）:** 既定は黒
  - **コントラスト（暗さ）:** 10〜100%（既定 60%）
  - **半径（明るい部分の半径）:** 40〜600（既定 150。macOS は pt、Windows は 96 DPI 換算の px）
  - **ぼかし（縁のぼかし）:** 0〜100%（既定 35%）
- **動作モードの廃止:** 以前の「動作モード」（スポットライト / ハイライト）はなくなり、常にスポットライトとして動作します。「ハイライト」の設定（色・不透明度・半径・ぼかし）は、カスタムカーソルの「ハイライトカーソル」に移りました（設定値はそのまま引き継がれます）。
- **キャプチャ**（新規グループ。「全般」の下。以前の「全般」グループの「クリック時の動作」は廃止）**:**
  - **有効**（既定: 無効）**:** 無効の場合は、クリックはそのまま背後のアプリに届きます。有効の場合は、左クリックすると、キャプチャモードの選択ウインドウは表示せずに、「対象」をスポットライトの表示（周囲の暗さ）を含めてキャプチャします（クリックはアプリには届きません）。以前の「クリック時の動作」を「デスクトップをキャプチャ」にしていた場合は、有効として引き継ぎます。
  - **対象**（ラジオボタン。既定: デスクトップ）**:**
    - **ウインドウ:** マウスカーソルが重なっているウインドウ（開いているドロップダウンリスト・メニューを含む）の範囲をキャプチャします。どのウインドウにも重なっておらず、デスクトップの上にマウスカーソルがある場合は、アクティブなデスクトップをキャプチャします。
    - **デスクトップ:** アクティブなデスクトップ（マウスカーソルのあるディスプレイ）をキャプチャします。
    - どちらも、撮影する時点（遅延時間のカウントダウンの後）のマウスカーソルの位置で決めます。
  - **遅延時間**（すぐに撮影〜10 秒。既定: すぐに撮影）**:** クリックしてから撮影するまでカウントダウンします（「キャプチャ」タブの「遅延時間」と同じ表示）。カウントダウンの間は、クリックがアプリに届くため、ドロップダウンリスト・メニューを開いた状態をキャプチャできます（カウントダウンの間にマウスカーソルを動かして、スポットライトの位置も決められます）。
  - **ほかの設定:** このグループにない設定（撮影音・マウスカーソルのキャプチャ・デスクトップのアイコン・壁紙・キャプチャ後の動作・保存先など）は、「キャプチャ」タブの設定に従います。遅延時間はこのグループの値を使うため、キャプチャモードとスポットライトモードで別々の値にできます。
- **以前の設定:** ライトモードで使っていた設定（トリガーキーを含む）は、そのまま引き継がれます。

### ウインドウサイズ

クリックしたウインドウの大きさを、プリセットから選んだ大きさに変えるモードです（新規。設定の「モード」の「スポットライト」の次）。資料用の画像を、いつも同じ大きさのウインドウで撮影したい場合などに使います。

- **使い方:** モードを開始すると（メニューのモードの一覧の「ウインドウサイズ」・トリガーキー・「キー設定」の「ウインドウサイズの開始」）、キャプチャモードの「ウインドウ」と同じように、マウスカーソルの下のウインドウを明るく示し、ウインドウの名前と大きさ（見た目の大きさ）を表示します。ウインドウをクリック（左右どちらでも）すると、マウスカーソルの位置にプリセットの一覧を表示し、選んだ大きさにウインドウの大きさを変えます（クリックはアプリには届きません）。変えた後もモードは続きます。
- **大きさの単位:** 見た目の大きさです（macOS は pt、Windows は 96 DPI 換算のピクセル。Retina・表示倍率 150% などのディスプレイでは、実際のピクセル数は倍率を掛けた数になります）。
- **変えられない場合:** 理由を画面に表示します（例: 大きさが固定されているウインドウ、全画面（フルスクリーン）表示中、最小化中、アクセシビリティの権限が無い（macOS）、管理者として実行しているアプリケーション（Windows）など）。アプリケーションの最小・最大の大きさの制限で指定した大きさにならなかった場合は、実際の大きさを表示します。最大化しているウインドウ（Windows）は、元の大きさに戻してから変えます。
- **デスクトップをクリックした場合:** デスクトップ（ウインドウが無い位置。Windows はタスクバーも）には「ウインドウの大きさ」が無いため、モードを終了します。ESC キーでも終了します。
- **設定（「ウインドウサイズ」タブ）:**
  - **外枠を含める**（既定: 有効）**:** 有効なら、タイトルバーとウインドウの影を含めた大きさを、プリセットの大きさにします（影の大きさはキャプチャの「ウインドウの影」と同じため、影ごと撮影した画像の大きさがプリセットの大きさになります。macOS の影の大きさは macOS 14 以降・画面収録の権限がある場合に求め、求められない場合は影を含めません）。無効なら、タイトルバー・枠を除いたウインドウの中身の大きさを、プリセットの大きさにします（macOS のタイトルバーの高さは、ボタン・ツールバーの位置から求めた目安です）。
  - **位置の自動調整**（既定: 有効）**:** 大きさを変えたウインドウが画面の外に出る場合に、できるだけ画面（macOS は Dock・メニューバー、Windows はタスクバーを除く）の中に収まるよう、ウインドウを動かします。
  - **プリセット:** 初期値は 1920 x 1080 / 1600 x 1080 / 1440 x 1080 / 1280 x 1024 / 1280 x 800 / 1024 x 768 / 800 x 600 / 640 x 480 です。幅・高さ（100〜10000）を入力して追加し、行ごとに削除でき、行をドラッグして並べ替えられます。同じ大きさは追加できません。
- **キー設定:** 「キー設定」タブの「ウインドウサイズ」グループに「ウインドウサイズの開始」（既定: なし）を追加しました。押すとウインドウサイズモードを開始し、実行中なら終了します。トリガーキーの「モード」でも「ウインドウサイズ」を選べます。
- **権限:** macOS では、ほかのアプリケーションのウインドウを操作するため「アクセシビリティ」の権限が必要です。

### キャプチャ

画面をキャプチャするモードです（以前の「カメラ」モード）。設定の「キャプチャ」タブで設定します。

- **選択ウインドウ:** モードを開始すると、画面（マウスカーソルのあるディスプレイ）の、「キャプチャ」タブの「全般」の **位置**（既定: 下）で指定した場所に、撮影する対象を選ぶ小さなウインドウを表示します（macOS の「スクリーンショット」と同じような表示）。位置は、左上 / 上 / 右上 / 左 / 右 / 左下 / 下 / 右下 から選びます（上・下は画面の端から画面の高さの 4% の所、左・右は画面の端から 40 pt（Windows は 96 DPI 換算で 40 px）の所）。左から **閉じる**（× のアイコン）・撮影する対象のボタン（デスクトップ / ウインドウ / 選択範囲 / 文字認識）・区切り・遅延時間・撮影音・カーソル・ウインドウの影・キャプチャ後の動作 の順に並びます。ボタンをクリックして対象を選びます。選んだ対象は、次にモードを開始したときも選んだままです（既定は「ウインドウ」）。
  - 「位置」の下の **サイズ**（新規。小 / 中（既定）/ 大 / 特大。ラジオボタン）で、選択ウインドウの大きさ（ボタン・アイコン・文字の大きさ。小は中の 0.8 倍、大は 1.25 倍、特大は 1.6 倍。特大は高解像度のディスプレイ向け）を選べます。次にキャプチャモードを開始したときから反映します。
  - 「位置」が「左」「右」の場合だけ、選択ウインドウのボタンを縦に並べます（画面の高さに収まるよう、ボタンはアイコンの右に名前を置いた横長の形になり、「遅延時間」などのメニューは画面の内側に向けて横に開きます）。それ以外の位置では、これまでどおり横に並べます。
  - **閉じる:** キャプチャモードを終了します。
  - **デスクトップ:** クリックした位置を含むデスクトップ（ディスプレイ）をキャプチャします。
  - **ウインドウ:** クリックしたウインドウをキャプチャします（他のウインドウに隠れている部分も含めて撮影します。アクティブなウインドウは変わりません）。
  - **選択範囲:** ドラッグした範囲をキャプチャします（ドラッグしている間は、範囲の外が暗くなり、範囲の大きさを表示します）。
  - **文字認識**（新規。「選択範囲」の右）: ドラッグした範囲の文字・QR コードを読み取ります（撮影はしません）。読み取った後の動作（文字認識後の動作など）は「文字認識」タブの設定に従います。「連続してキャプチャ」がオフの場合は、1 回読み取るとモードを終了します。「文字認識」を選んでいる間は、遅延時間・撮影音・カーソル・キャプチャ後の動作は使えません（ウインドウの影は「ウインドウ」のときだけ使えます）。
  - 区切りの右側の **遅延時間**（タイマーのアイコンの下に「すぐに撮影」「1秒」「2秒」…「10秒」と表示。メニューの項目も同じ表示）・**撮影音**（クリックするたびにオン / オフを切り替え）・**カーソル**（カーソルのキャプチャ）・**ウインドウの影**（「ウインドウ」のときだけ）・**キャプチャ後の動作**（ファイルに保存 / クリップボードにコピー / ファイルとクリップボード / MiraPaint。アイコンの下に「ファイル」「クリップボード」「ファイルとコピー」「MiraPaint」と今の値を表示）は、モードを開始したときに「キャプチャ」タブの「初期設定」「全般」の値で始まります。ここで変えた値は、そのキャプチャモードの間だけ使います（設定は変わりません）。
- 左クリック・右クリックのどちらでも同じです。クリックは背後のアプリには届きません。「キャプチャ」タブの「全般」の **連続してキャプチャ**（既定: オフ。以前はオン）がオンの場合は、モードを終了するまで続けて何回でもキャプチャできます。オフの場合は、1 回キャプチャするとモードを終了します。
- **撮影する対象の表示:** マウスを動かすと、撮影する対象が次のように変わります。「選択範囲」の場合と、選択ウインドウの上では表示しません。この表示は撮影する画像には写りません。
  - **ウインドウ:** マウスカーソルの下のウインドウの見えている部分以外を暗くし、見えている部分の縁を色付きの枠で囲みます（手前の他のウインドウに隠れている部分には枠を描きません）。マウスカーソルの近くに「アプリ名 — ウインドウ名　幅 × 高さ」を表示します。
  - **デスクトップ:** マウスカーソルのあるデスクトップ（ディスプレイ）を色付きの枠で囲み、ほかのデスクトップを暗くします。マウスカーソルの近くに、デスクトップの名前（macOS はディスプレイ名、Windows は「デスクトップ N」）と大きさ（幅 × 高さ）を表示します。
- 連続してキャプチャ・キャプチャ後の動作・選択ウインドウの位置は「キャプチャ」タブの「全般」で、遅延時間・撮影音・カーソルのキャプチャ・ウインドウの影をキャプチャ・デスクトップアイコンをキャプチャ・壁紙をキャプチャ・壁紙の代わりの背景色は「初期設定」で、撮影後のプレビュー（表示位置・表示時間・サイズ）は「プレビュー」で設定します（遅延時間などは、ペンモードのキャプチャと共通）。
- **デスクトップアイコンをキャプチャ**（「初期設定」。新規。既定: 有効）**:** 無効にすると、「選択範囲」「デスクトップ」など画面の範囲を撮影するときに、デスクトップのアイコンを写さずに撮影します。キャプチャモードの選択ウインドウでは「アイコン」で、そのモードの間だけ切り替えられます。
- **壁紙をキャプチャ**（新規。既定: 有効）**:** 無効にすると、画面の範囲を撮影するときに、壁紙を写さず「壁紙の代わりの背景色」で塗って撮影します。選択ウインドウでは「壁紙」です。
- **壁紙の代わりの背景色**（新規。既定: 青 `#007AFF`）**:** 「壁紙をキャプチャ」が無効なときに、壁紙の代わりに塗る色です（「壁紙をキャプチャ」が有効の間は変更できません）。選択ウインドウの「背景色」では、青 / 薄い青 / 白 / 薄い灰色 / 灰色 / 黒 / 薄い緑 / 薄い黄 / 薄いピンク（設定の色がこれら以外なら「設定の色」も）から選べます。
- アイコン・壁紙を写さない設定は、ウインドウだけを撮影する場合（「ウインドウ」でウインドウをクリックした場合）には使いません。macOS では撮影する画像からだけ除き、画面の表示は変わりません。Windows では撮影する一瞬だけ、画面のアイコン・壁紙を実際に隠して撮影し、撮影後すぐに元に戻します（壁紙は、元に戻るときに一瞬切り替わって見えることがあります）。遅延時間の 0 秒は「すぐに撮影」と表示します。選択ウインドウは撮影する画像には写りません。
- **ESC キーで終了（変更）:** キャプチャモードは、どの方法で開始した場合でも（メニュー・「キャプチャの開始」のショートカットキー・トリガーキーなど）、**ESC** キーを短く 1 回押すだけで終了します。ただし、終了方法が「キーの長押し」のトリガーで、トリガーキーの長押しで開始した場合だけは、ESC キーを押すだけでは終了しません（トリガーキーをもう一度長押しするか、下の ESC キーの長押しで終了します）。以前は、終了方法が「ESCキー」「キーを離す」の場合だけ ESC キーで終了していました。
- **ESC キーの長押し:** キャプチャモードの間に **ESC** キーを「強制終了の長押し」の時間だけ長押しすると、必ずキャプチャモードを終了します。遅延時間のカウントダウンの途中の場合は、撮影を取り消してから終了します（撮影しません）。
- 以前の「左クリック」「右クリック」ごとの対象（「確認する」「なし」「選択範囲から文字/QRコード読み取り」を含む）とキャプチャ設定の上書き、「クリック時の動作を表示」は廃止しました。選択範囲から文字/QRコードを読み取るには、選択ウインドウの「文字認識」を使います（以前は「選択範囲から文字/QRコード読み取り」のショートカットキーでしたが、廃止しました）。

### 🔍 ズーム

マウスカーソルの周りを拡大して、カーソルの近くに表示します（ルーペ）。以前の「カラーピッカー」と「座標」の機能も、このモードに含まれています。

- **トリガーキー:** 既定ではトリガーがありません。使う場合は、設定の「キー設定」タブの「トリガーキー」グループの「トリガーを追加」でトリガーを追加してください。
- **表示する位置:** カーソルから見て「左上」「上」「右上」「左」「右」（既定。以前は「右下」）「左下」「下」「右下」の 8 つのボタン（位置のとおり 3×3 に並んでいて、真ん中は空いています。以前は「左上」「右上」「左下」「右下」の 4 つ）から選べます。「上」「下」ではカーソルの真上・真下に、「左」「右」ではカーソルの真横に拡大表示を出します（座標と色の情報は、拡大表示の下に出ます）。画面からはみ出す場合は、反対側に表示します。
- **左クリック / 右クリック:** 「クリック時の動作」は、なし / ズーム設定の一時変更（以前の「ズーム設定の変更」。押している間だけ拡大率・サイズを変える）/ 色空間情報をコピー から選びます（以前あった「拡大部分をキャプチャ」「拡大部分から文字/QRコード読み取り」「選択範囲から文字/QRコード読み取り」は廃止しました。これらを選んでいた場合は既定値（左 = ズーム設定の一時変更、右 = 色空間情報をコピー）になります）。**拡大表示の位置を反転**（既定: 無効。以前の「位置」）を有効にすると、そのボタンを押している間だけ、拡大表示を「表示する位置」の反対側（右 → 左、右上 → 左下など）に移します。
- **全般グループ:** 以前の「ズーム」グループです。上から 位置・サイズ・形・拡大率・距離・クリック時の動作を表示 の順に並んでいます（「拡大率」は「距離」のすぐ上に移り、「クリック時の動作を表示」は以前の「表示」グループから移りました）。
- **サイズ（以前の「大きさ」）:** 200〜1200（20 刻み、既定 300。macOS は pt、Windows は 96 DPI 換算の px。以前は 0〜1200、その前は 80〜1000）。以前に 200 未満にしていた場合は 200 になります。左クリック / 右クリックの「ズーム設定の一時変更」の「大きさ」は、これまでどおり 0〜1200 です（0 にすると拡大表示は表示されません）。
- **形:** 「四角」（既定。以前の「四角形」）または「丸」（以前の「円形」）。macOS・Windows とも、ラジオボタンで選びます（以前の macOS はセグメント、Windows はドロップダウンリスト）。
- **拡大率:** 1.5〜20.0 倍（0.5 刻み、既定 3.0 倍）
- **距離:** カーソルから拡大表示・座標と色の情報（吹き出し）までの距離です（0〜400、10 刻み、既定 40。以前は 0〜200・20 刻み）。
- **十字線の表示:** 「十字線の表示」のグループで、座標と十字線を設定します。
  - **X/Y 座標を表示する**（既定: オン）**:** オンにすると、拡大表示の横の吹き出しにカーソル位置の X / Y 座標を表示します。「色空間情報を表示する」もオンのときは、同じ吹き出しに色の情報も表示します。
    - macOS: メインディスプレイの左上を原点とした値（pt）
    - Windows: すべてのモニターを合わせた画面上の物理ピクセル（メインモニターの左上が 0, 0）
  - **種類:** マウスカーソルを中心にした十字線の種類です。一番上の「なし」を選ぶと、十字線を表示しません（以前の「有効」（線を表示する）はなくなり、「なし」に置き換えました。以前に無効にしていた場合は「なし」になります）。「なし」のときは、太さ・不透明度・色は変更できません。
  - **線の色:** 既定はグレー
  - **線の太さ:** 1〜10（既定 1）
  - **線の不透明度:** 10〜100%（既定 80%）
  - **線の種類:** 実線 / 破線（既定）/ 点線 / 一点鎖線 / 二重線（新規）/ 二重破線 / 二重点線
- **拡大のしかた:** ピクセルをぼかさずに、そのまま拡大します。MiraCursor が画面に重ねて描く表示（拡大表示・吹き出し・トーストなど）は、拡大画像に映りません。設定ウインドウは、ほかのアプリのウインドウと同じように拡大画像に映ります。
- **色空間情報を表示する**（既定: オン）**:** 「色空間情報」のグループにあります。オンにすると、拡大表示の下（または上）にカーソル位置の色の値を表示し、拡大表示の中のカーソル位置のピクセルを小さな枠で示します。次の設定は、これをオンにしたときだけ使えます。
  - **色空間:** 同じ「色空間情報」のグループの「色空間情報を表示する」の下で、sRGB / Display P3 / ネイティブ値 / Generic RGB / Adobe RGB から、表示するものを選べます（複数選択可）。
  - **色空間情報の表示形式:** 10 進数 `RGB(255,0,0)` / 16 進数 `#FF0000` / パーセンテージ `RGB(100.0%,0.0%,0.0%)` から選べます（複数選択可）。
  - **色空間情報をコピーする**（既定: オン。以前の「マウスクリックで色空間情報をコピーする」）**:** 「マウスクリック時の動作」のグループにあります。クリックすると、色の値をクリップボードにコピーし、「コピーしました」と表示します。
    - **コピーする文字列の形式:** 10 進数 `RGB(255,0,0)` / 16 進数 `#FF0000`（既定）/ パーセンテージ `RGB(100.0%,0.0%,0.0%)` から選べます。
    - **コピーする色空間情報:** コピーする値の色空間を選べます（既定は sRGB）。
- **クリックの扱い:** 「色空間情報を表示する」と「色空間情報をコピーする」の両方がオンのときだけ、クリックを MiraCursor が受け取ります。どちらも既定でオンのため、既定ではクリックで色をコピーし、クリックは背後のアプリに届きません。どちらかをオフにすると、クリックは背後のアプリにそのまま届きます。
- **カーソルの形:** ズームモードの間、マウスカーソルは虫眼鏡のアイコンになります（設定で無効にできます）。
- **macOS の場合:** 「画面収録」の権限が必要です。また、macOS 14 Sonoma 以降でのみ使えます。
- **画面共有:** 拡大表示・十字線・座標は画面に重ねて描くため、特定のアプリのウインドウだけを共有している場合は相手に映りません。
- **以前の設定:** カラーピッカーで使っていた設定（トリガーキーを含む）は、そのまま引き継がれます。以前の「座標」モードの十字線の設定（色・太さ・不透明度・種類）は、ズームの「十字線の表示」に引き継がれます（座標モードのトリガーキーと、照準のアイコンはなくなりました）。

### キーモニタ

キーボードで押したキーを、画面に表示します（新規）。ショートカットキーの操作を説明するときなどに使えます。

- **トリガーキー:** 既定ではトリガーがありません。メニューから始めるか、設定の「キー設定」タブの「トリガーキー」グループの「トリガーを追加」でトリガーを追加してください。終了方法に「キーを離す」は選べません（トリガーキーを押したままではキー入力を表示できないため。トリガーのモードをキーモニタに変えると、「キーを離す」は「ESCキー」に変わります）。
- **表示するキー:** 「a」のような 1 つのキーだけでなく、「⇧ + A」（Windows は「Shift + A」）のような修飾キーとの組み合わせも表示します。修飾キーだけを押して離した場合も表示します。キーを押し続けて繰り返し入力された分は、アイコンを増やしません。押したキーは、アプリにそのまま届きます。
- **表示する文字:** キーボード配列の文字を表示します。IME で変換中の文字（日本語など）は表示できません。かな入力の場合は、かな配列の文字を表示します。
- **タブの構成:** 上から「表示」（見た目（以前の「方式」）・自動的に位置調整・位置・距離・自動的に隠すまでの時間）、「色」、「スクロール」、「キーボード」、「統計情報」のグループと、「既定値に戻す」の順です。
- **見た目（以前の「方式」）:** 「表示」グループで「スクロール」（既定）か「キーボード」を選びます。
  - **スクロール:** 押したキーのアイコンを右に追加して並べます。表示しきれない古いアイコンは左へ流れて消えます（常に最新のキー入力を表示します）。「スクロール」グループの **幅**（120〜1600、40 刻み、既定 480）で並べられる数が、**高さ**（20〜200、8 刻み、既定 60。20 から 8 刻みのため、選べる最大の値は 196）でキーのアイコンの大きさが決まります（macOS は pt、Windows は px）。
  - **キーボード:** キーボードの絵を表示し、押しているキーを「入力キーの色」で表示します（離した後は、少しずつ「未入力キーの色」に戻ります）。「キーボード」グループの **サイズ**（キー 1 つ分の大きさ。20〜80、4 刻み、既定 32。macOS は pt、Windows は px（96 DPI 換算））で、キーボードの絵の大きさを選べます。キーボードの種類は自動で判定します（macOS は JIS / ISO / ANSI、Windows は日本語 106/109 か英語 101/104）。テンキーのキーを押すと、テンキー付きのキーボードと判断してテンキーも表示します。
  - 「見た目」に合わないグループ（「見た目」が「スクロール」なら「キーボード」、「キーボード」なら「スクロール」）は、無効表示になります。
- **自動的に位置調整:** 既定は有効。マウスカーソルが表示に近づくと（表示の範囲の周り 30 の内側）、表示を反対側（左上→右上、右上→左上、上→下、下→上、左→右、右→左、左下→右下、右下→左下）に移します。マウスカーソルが十分に離れると（周り 80 の外）、元の位置に戻します。「表示」グループの「位置」の上にあります。
- **位置:** 「モニタ」で選んだディスプレイの作業領域（メニューバー・Dock／タスクバーを除く）から見て「左上」「上」「右上」「左」「右」「左下」（既定）「下」「右下」の 8 つのボタンから選べます（マウスカーソルからの位置ではありません）。画面からははみ出しません。
- **モニタ:** キー入力を表示するディスプレイを「アクティブなモニタ」（既定。マウスカーソルのあるディスプレイ。マウスカーソルを別のディスプレイに移すと、表示も移ります）か「モニタ1」「モニタ2」…から選びます。選択肢は、ウィジェットの「モニタ」と同じです。
- **距離:** 0〜400（10 刻み、既定 40。macOS は pt、Windows は px）。「位置」で指定した画面の端（角）から、表示までの距離です。
- **自動的に隠すまでの時間:** 0〜20 秒（0.5 秒刻み、既定 8.0 秒）。キー入力が無いまま、この時間が過ぎたら表示（統計情報の情報ウインドウも）を隠します。0 秒にすると、キー入力が無くても常に表示します。
- **色:** 「色」グループで設定します。
  - **入力キーの色 / 未入力キーの色:** 既定は入力キーの色が #FF9500（オレンジ）、未入力キーの色が #F2F2F2（明るいグレー）です。「スクロール」「キーボード」のどちらでも使います。キーボードで押している間のキーは、入力キーの色です。キーの文字は、塗りの明るさに合わせて黒か白で表示します。
  - **未入力とみなすまでの時間:** 0.0〜5.0 秒（0.1 秒刻み、既定 0.5 秒）。キーを入力してから（キーボードはキーを離してから）この時間は、入力キーの色のままです。
  - **グラデーション表示の時間:** 0.0〜5.0 秒（0.1 秒刻み、既定 1.5 秒）。「未入力とみなすまでの時間」が過ぎた後、入力キーの色から未入力キーの色へ、グラデーションで徐々に変えていく時間です。0 秒にすると、すぐに未入力キーの色になります。
- **統計情報:** 「統計情報」グループの「有効」（既定: 有効。以前は無効）を有効にすると、キー入力の表示とは別の情報ウインドウ（キー入力の表示の上。画面の上側で入らない場合は下）に、タイピング数などを「1分間: n   5分間: n   10分間: n   1時間: n   合計: n   削除キー: 100 (0.01%)」のように表示します。表示する項目は「1分間」「5分間」「10分間」「1時間」「合計」（以前の「本日の合計」）「削除キー」（以前の「本日の削除キー」、その前は「Backspace」）で選べます（既定は「合計」「削除キー」が有効、「1分間」「5分間」「10分間」「1時間」が無効（以前はいずれも有効）。「有効」が無効の間は操作できません）。情報ウインドウは「自動的に隠すまでの時間」に従って隠れます。
  - タイピング数は、文字などのキーを押した回数です（修飾キーだけ・押し続けた繰り返しは数えません）。キーモニタモードを使っていない間も、MiraCursor の起動中は数えます。「1分間」「5分間」「10分間」「1時間」は直近のその時間の数、「合計」は MiraCursor を起動してからの合計です。
  - 「削除キー」（以前の「本日の削除キー」、その前は「Backspace」）は、MiraCursor の起動中に削除キー（Backspace と DEL の両方。macOS は delete キーと forward delete キー）を押した回数の合計です。情報ウインドウには、「削除キー: 100 (0.01%)」のように、回数と「合計」に占める割合（小数点以下 2 桁）を「合計」の後ろに表示します（以前は「⌫」のアイコンの後に回数を表示していました）。
  - 統計はメモリだけに持ち、MiraCursor を終了すると破棄します。設定ファイルにも保存しません（保存するのは、各項目のオン・オフの設定だけです）。
- **既定値に戻す:** キーモニタのタブの「既定値に戻す」で、キーモニタの設定を初期値に戻せます。
- **画面共有:** 画面に重ねて描くため、特定のアプリのウインドウだけを共有している場合は相手に映りません（タブの上部と、「トリガーキー」の一覧のキーモニタを選んだ行に「⚠ ウインドウ共有時は反映されません」と表示されます）。

### ウィジェット

（以前の「システム状態」。さらに以前は「マイクレベル」）AI（Claude Code・Codex）の利用状況、CPU・メモリの使用率、マイクの入力レベル（音量）と、カレンダー（日本の祝日付き。新規）を、画面の隅に並べて表示します。プレゼンテーションやデモの最中にコンピュータの負荷を確かめたり、オンライン会議で自分の声がマイクに入っているかを確かめたり、Claude Code・Codex の利用の枠の残りを確かめたりするときに使えます。モードではないため、トリガーキーは使いません。設定の「ウィジェット」タブ（以前の「マイクレベル」タブ）で設定します。タブは、上から 注意 / 全般 / AI（新規）/ CPU / メモリ / マイク入力 / 表示順序（新規）のグループです。

- **有効**（「全般」グループ。既定: オフ）をオンにすると、「AI」（Claude Code・Codex）「CPU」「メモリ」「マイク入力」のうち有効にしたものを、「表示順序」の順に並べて、モードを実行していない間も表示し続けます。
- **表示する項目:** 「AI」グループの「Claude Code」（既定: オフ）・「Claude Code (WSL)」（新規。Windows のみ。既定: オフ）・「Codex」（既定: オフ）と、「CPU」（既定: オフ）・「メモリ」（既定: オフ）・「マイク入力」（既定: オフ。以前はオン）の各グループの「有効」で、表示する項目を選びます。有効にした項目を、「表示順序」の順に、半透明の黒い角丸の表示（タイル）で「方向」の向き（横 / 縦）に並べます。どれも有効にしていない場合（または「全般」の「有効」がオフの場合）は、何も表示しません。
- **表示順序（新規）:** 「全般」グループの下（以前はタブの一番下）の「表示順序」グループで、Claude Code・Claude Code (WSL)（Windows のみ）・Codex・CPU・メモリ・マイク入力 の項目の行をドラッグ＆ドロップして並べ替えると、画面にはこの順に左から並べます。行をドラッグして項目の間にドロップすると、そこに挿入します（ドロップ先の行の上半分なら前、下半分なら後ろに挿入。挿入する位置に青い線を表示します。以前は、ドロップ先の行の位置に移していたため、入れ替えのように見えていました）（既定: Claude Code → Claude Code (WSL) → Codex → CPU → メモリ → マイク入力）。以前のバージョンで並べ替えていた場合、「Claude Code (WSL)」は「Claude Code」のすぐ後ろに入ります。無効にしている項目は「無効」と表示します（画面には表示しません）。「既定値に戻す」で既定の順に戻ります。
- **AI（新規）:** 「Claude Code」「Codex」を有効にすると、それぞれの利用の枠の使用率と、枠が戻るまでの時間を表示します。Claude Code は 5 時間の枠・週間の枠と、ある場合はモデル別（Opus・Sonnet）の週間の枠・追加の利用、Codex は 5 時間の枠・週間の枠と、ある場合は追加の枠・コードレビューの枠です。
- **Claude Code (WSL)（新規。Windows のみ）:** WSL（Windows Subsystem for Linux）の中で使っている Claude Code の利用状況とコストを、「Claude Code」（Windows の Claude Code）とは別のタイルで表示します。どちらを表示するかは、「Claude Code」と「Claude Code (WSL)」のスイッチで選びます（両方オンにすると両方を表示します）。
  - **wsl.exe のパス:** 「Claude Code (WSL)」の下で、WSL が起動しているかを確かめるために使う wsl.exe の場所を指定できます（既定: WSL をインストールしたときの標準の場所 `C:\Windows\System32\wsl.exe`）。「選択...」で wsl.exe を選び、「既定に戻す」で標準の場所に戻します。指定したパスに wsl.exe が無い場合は、「⚠ 指定したパスに wsl.exe がありません。「選択...」で wsl.exe の場所を明示的に指定してください。」と表示し、「Claude Code (WSL)」は有効にできません。
  - 読むのは、WSL の **既定のディストリビューション**（`wsl -l` で「(既定)」と表示されるもの）の、既定のユーザー（`/etc/wsl.conf` の `[user]` の `default=` で指定している場合はそのユーザー。以前はこの指定を見ていなかったため、`/root` を読んで「OAuth でログインしていません」と表示されることがありました）の `~/.claude`（ログイン情報は `~/.claude/.credentials.json`、会話の記録は `~/.claude/projects`・`~/.config/claude/projects`）だけです。ほかのディストリビューション・ユーザーと、WSL の中で設定した `CLAUDE_CONFIG_DIR` は対象外です。
  - 止まっている WSL を起動してしまわないよう、**WSL が起動している間だけ** 読みます。WSL が止まっている間は、前回の値を残したまま「WSL が停止中」と表示します。設定画面でも、WSL が起動していない場合は有効にできません（WSL を起動してから「ログインの状態を再確認」を押してください）。WSL がインストールされていない場合も有効にできません。
  - 「Claude Code」と同じアカウントでログインしている場合、利用状況（枠の使用率）は同じ値になります。コストは、それぞれの会話の記録から別々に計算します。
  - WSL のファイルは Windows のファイルより読むのが遅いため、最初のコストの計算に時間がかかる場合があります。
- **AI のログイン:** それぞれのツールに OAuth でログインしている場合だけ有効にできます（Claude Code は Claude のアカウント、Codex は ChatGPT のアカウント。Codex の API キーでのログインは対象外です）。スイッチの下に、「OAuth でログイン済み（プラン）」か、有効にできない理由を表示します（ログインしていない場合は、ターミナルで `claude` を起動してログインする / `codex login` を実行する。Claude Code のログイン情報に利用状況を読む権限（user:profile）が無い場合は、`claude` で一度ログアウトしてログインし直す）。ログインした後は「ログインの状態を再確認」を押してください。
- **サイズ（ウィジェットごと）:** 以前の「全般」の「サイズ」（すべてのウィジェットで共通）は廃止し、Claude Code・Claude Code (WSL)（Windows のみ）・Codex・CPU・メモリ・マイク入力・カレンダーのそれぞれのグループ（AI はサブグループ）に「サイズ」（表示の高さ。40〜200・8 刻み、既定 80。macOS は pt、Windows は 96 DPI 換算の px）を置きました。特定のウィジェットだけを大きくできます。「全般」の「方向」の下の **サイズの一括変更**（40〜200・8 刻み、既定 80）を動かすと、すべてのウィジェット（無効にしているものも含む）の「サイズ」をまとめてその値にします（後からウィジェットごとの「サイズ」を変えても、「サイズの一括変更」の値は変わりません）。以前に「全般」の「サイズ」を変えていた場合は、その値をすべてのウィジェットの「サイズ」として引き継ぎます。大きさの違うウィジェットは、「方向」が横のときは「位置」の側（上・中央・下）で、縦のときは「位置」の側（左・中央・右）でそろえます。
- **全てのモニタ:** 「全般」の「モニタ」で「全てのモニタ」（「アクティブなモニタ」の次）を選ぶと、すべてのモニターに同じ内容を表示します。「位置の自動調整」は、モニターごとに働きます。キーモニタの「モニタ」でも同じく選べます。
- **AI の表示:** タイルは幅が「サイズ」の 4.2 倍、高さが「サイズ」です。上にツールの名前とプラン（Codex はクレジットの残高も）、その下に最大 4 行、「名前（5時間・週間・Opus・Sonnet・追加・レビューなど）· 横向きのバー · 使用率（%）· 枠が戻るまでの時間（例: 25分・3時間・4日・まもなく）」を並べます。バーは使用率に応じて緑 → 黄 → 赤になります。行が多いほど文字が小さくなります。右端には、区切り線を挟んで「本日」「30日間」のコスト（下記）を表示します。
- **AI のコスト（新規）:** Claude Code・Codex がこのコンピュータに保存している会話の記録（JSONL）のトークン数に API の料金を掛けた、「本日」（今日の 0 時から）と「30日間」（本日を含む 30 日）の金額の目安を、日本円で表示します（例: ¥16,311。100 万円以上は ¥1.2M のように表示。計算が終わるまでは「…」。[CodexBar](https://github.com/steipete/CodexBar) と同じ計算方法です）。定額のプランを使っている場合も、API を従量課金で使った場合の金額で、実際の請求額ではありません。料金は models.dev、為替レート（ドル → 円）は open.er-api.com から 1 日 1 回取得します（取得できない場合は、組み込みの料金と 1 ドル = 150 円で計算します）。料金表に無いモデルは数えません（0 円）。コンテキストの長さによる料金の違いは考慮しません。利用状況と同じく 5 分ごとに計算します。初回は 30 日分の記録を読むため、数秒かかる場合があります。
- **AI の「トークン」「料金」（新規）:** 「AI」グループの一番上に **トークン**（既定: 有効）と **料金**（既定: 無効）を追加しました。「トークン」はトークンの使用状況（5 時間の枠・週間の枠などの使用率と、枠が戻るまでの時間・プラン）、「料金」は料金状況（本日・30 日間の費用）の表示です。無効にした部分は表示せず、取得・計算もしません。「トークン」だけなら費用の列の無いウィジェット、「料金」だけなら名前と本日・30 日間の費用だけの小さなウィジェットになり、両方を無効にすると Claude Code・Codex のウィジェットは表示しません。料金しきい値は、「料金」が無効の間は変更できません。以前は常に両方を表示していたため、既定では料金を表示しなくなります。
- **AI の料金しきい値（新規）:** 「AI」グループの一番下の **本日の料金しきい値**（既定: ¥10,000）・**30日間の料金しきい値**（既定: ¥100,000）（どちらも 0〜200,000 円、1,000 円刻み。0 は「なし」で、金額の文字の色を変えません（白のまま））で、タイルの右端の「本日」「30日間」の金額の文字の色を、しきい値に対する割合で変えます: 0〜20% は緑、21〜40% は黄緑、41〜60% は黄、61〜80% はオレンジ、81〜100% は赤、100% を超えると濃い赤（計算が終わるまでの「…」は白）。
- **AI の取得:** 5 分ごと（有効にしたときはすぐ）に取得し、枠が戻るまでの時間の表示は 30 秒ごとに更新します。取得できなかった場合は、前回の値を残したまま、タイルの右上に黄色の文字で理由を表示します（まだ値が無い場合は中央に表示）。理由は、ログインの期限が切れた場合は「期限切れ（claude を起動）」「期限切れ（codex を起動）」、取得の回数の制限にかかった場合は「取得の制限中」、ネットワークにつながらない場合は「通信できません」などです。MiraCursor はログイン情報を更新しないため、期限が切れた場合は Claude Code・Codex を一度起動してください。
- **AI のプライバシー:** Claude Code・Codex が保存している OAuth のログイン情報（macOS の Claude Code はキーチェーンの「Claude Code-credentials」（無い場合は `~/.claude/.credentials.json`）、Windows の Claude Code は `%USERPROFILE%\.claude\.credentials.json`、WSL の Claude Code は WSL の既定のユーザーの `~/.claude/.credentials.json`、Codex は `~/.codex/auth.json`（Windows は `%USERPROFILE%\.codex\auth.json`））を、取得のたびに読んでメモリの中だけで使います。ログイン情報は保存・表示・記録せず、利用状況の取得のために Anthropic（`api.anthropic.com`）・OpenAI（`chatgpt.com`）の公式のサーバーにだけ送ります（[CodexBar](https://github.com/steipete/CodexBar) と同じ方法です）。macOS で、キーチェーンへのアクセスを確認するダイアログは表示されません。コストの計算では、会話の記録（Claude Code は `~/.claude/projects`、Codex は `~/.codex/sessions` など。Windows は `%USERPROFILE%` の下）から、トークン数・モデル名・時刻だけを読みます（会話の内容は読み取りません）。
- **AI の注意:** 利用状況の API は公開されているものではないため、予告なく使えなくなる場合があります（タブの「AI」グループにも注意を表示します）。
- **CPU・メモリの表示:** 上に名前（「CPU」「メモリ」）、中央に使用率のバー、下に使用率の数値（%）を表示します。バーは使用率に応じて下から塗られ、低いうちは緑、高くなると黄、とても高いと赤になります（マイク入力と同じ色）。コンピュータへの負荷を抑えるため、1 秒に 1 回取得します。
- **CPU の「複数コアの表現」:** 「全体の平均」（既定。すべてのコアの平均をバー 1 本で表示）・「コアごと」（コアの数だけ細いバーを並べます。コアが多い場合は表示が横に広がります。高性能コア・高効率コアなど、コアの種類が複数ある CPU では、種類ごとにバーの背景の色を変え、バーの下にその色の細い線を引くため、どのバーがどの種類のコアかを見分けられます（最も高性能な種類から順に 青・紫・水色・ピンク。使用率が高くバーが塗られていても、下の線で見分けられます）。種類が 1 つしかない CPU では、今までどおりの表示です）・「コアの種類ごと」（高性能コア・高効率コアなど、コアの種類ごとの平均のバーを、左から性能の高い順に並べます。バーの下の文字は種類の頭文字で、macOS は例えば S = Super、P = Performance、E = Efficiency（高効率）、Windows は P = 最も高性能、E = 最も高効率、M = その間です。種類が 1 つしかないコンピュータでは、バー 1 本になります）から選びます。数値は、どの表現でも全体の平均です。
- **メモリの使用率:** macOS はアクティビティモニタの「使用済みメモリ」（アプリケーションメモリ + 確保されているメモリ + 圧縮）、Windows はタスクマネージャーの「使用中」と同じ考え方で、物理メモリに対する割合を表示します。
- **カレンダー（新規）:** 「AI」グループの下（以前はタブの一番下）の「カレンダー」グループの **有効**（既定: オフ）をオンにすると、今月のカレンダー（日曜日始まり。その月の週の数（4〜6 週）だけの行）を表示します。幅は「サイズ」の 1.7 倍（以前は 2.2 倍。日付の間隔を狭くしました）、高さは「サイズ」です。同じグループの **年月**（以前の「年月の表示」。既定: なし）で一番上に年月を表示するかを、その下の **曜日**（既定: オフ。以前はオン）で日付の上に曜日（日〜土）を表示するかを選びます（なし / 西暦: 「2026年10月」/ 和暦: 「令和8年10月」/ 西暦と和暦: 「2026年10月 (令和8年)」。和暦は令和 2019 年 5 月 1 日から、平成 1989 年 1 月 8 日から。1 年目は「元年」）。曜日・年月を表示しない分、日付をできるだけ大きく表示し、カレンダー全体を上下の中央に置きます（以前は常に 6 週分の行を取っていたため、下に余白が残っていました。年月が表示の幅に収まらない場合は、年月の文字を小さくします）。平日は白、土曜日は青、日曜日は赤、祝日・休日（国民の祝日・振替休日・国民の休日）はオレンジの文字で、今日は黄色の丸で囲んで表示します。日付が変わると、表示も変わります（30 秒ごとに確かめます）。「表示順序」にも「カレンダー」が加わります（既定: 最後）。
- **カレンダーの「表示項目」（変更）:** 「カレンダー」グループの「サイズ」の下に「表示項目」サブグループを置き、**西暦**（既定: 有効）・**和暦**（既定: 有効）・**曜日**（既定: 無効）・**対象**（ラジオボタン。今週 / 今週と来週（既定）/ 今月）を設定します（以前の「年月」（なし / 西暦 / 和暦 / 西暦と和暦）は「西暦」「和暦」のチェックボックスにしました。どれも選ばなくても、いくつ選んでもかまいません）。年月は、西暦だけなら「2026年10月」、和暦だけなら「令和8年10月」、両方なら「西暦2026年/令和8年10月」（以前は「2026年10月 (令和8年)」）のように表示し、どちらも選ばなければ表示しません。「今週」は今日を含む週（日曜日から土曜日）の 1 行、「今週と来週」は 2 行、「今月」は以前と同じく今月の日付を表示します（今週・今週と来週で、前の月・次の月の日付は薄く表示します）。以前に保存した「年月」の設定は、そのまま「西暦」「和暦」に引き継ぎます。
- **「全般」「AI」の並び（変更）:** 「全般」の「方向」を **表示方向** に名前を変え、「サイズの一括変更」を「モニタ」の下に移しました。「AI」グループの先頭に「表示項目」サブグループを置き、「トークン」「料金」をその中に移しました。
- **表示順序の既定値（変更）:** カレンダーを AI の次にしました（Claude Code・(Windows のみ) Claude Code (WSL)・Codex・カレンダー・CPU・メモリ・マイク入力。以前はカレンダーが最後）。以前に保存した表示順序はそのまま使います（「既定値に戻す」で新しい順序になります）。
  - 祝日・休日は、MiraCursor に内蔵した「国民の祝日に関する法律」の規則（春分の日・秋分の日は 1980〜2099 年の計算式。2019 年の即位の日・即位礼正殿の儀と、2020・2021 年の東京オリンピック・パラリンピックに合わせた移動にも対応）で計算し、ネットワークには問い合わせません。その後に祝日が変わった場合は、MiraCursor をアップデートするまで反映されません。
- **マイク入力の表示:** 半透明の黒い角丸の背景に、白いマイクを描きます。声が入ると、マイクの頭の部分が音量に応じて下から塗られ、音量が小さいうちは緑、大きくなると黄、とても大きいと赤になります。入力レベルは 1 秒に 15 回取得します（以前は 30 回）。マイクは「マイク入力」が有効な間だけ使います。
- **モードとの同時表示:** ペン・キャプチャ・ズームなどのモードを実行している間も、モードの表示より手前に表示します（キャプチャモードで画面を暗くしている間も、暗くならずに見えます）。
- **マイクを使えないとき:** マイクが無い、権限が無いなど、マイクを使えない場合は、灰色のマイクに赤い斜線を引いたアイコンを表示します。
- **位置:** 「モニタ」で選んだディスプレイの、左上 / 上 / 右上 / 左 / 右 / 左下 / 下 / 右下 から選びます（既定: 右下）。メニューバー・Dock（Windows はタスクバー）を除いた範囲の端から 24 pt（Windows は 96 DPI 換算で 24 px）離して表示します。
- **位置の自動調整（新規）:** 「位置」の下のスイッチ（既定: 有効）です。有効な間は、マウスカーソルがウィジェットの表示に近づく（表示から 24 pt（Windows は 96 DPI 換算で 24 px）以内に入る）と、表示を反対側へ移し、カーソルが離れると元の「位置」に戻します。移す先は、左 ↔ 右、上 ↔ 下、左上 ↔ 右上、左下 ↔ 右下です（同じディスプレイの中）。近づいたかどうかは元の位置の範囲で判定するため、表示が行き来し続けることはありません。マウスカーソルの位置は 1 秒に 10 回確かめます。
- **方向（新規）:** 「位置」の下で、項目を並べる向きを「横」（既定。「表示順序」の順に左から右へ）か「縦」（上から下へ）から選びます。「縦」のときは、幅の違う項目（AI のタイルは CPU などより幅が広い）の端を「位置」の側にそろえます（位置が左側なら左端、右側なら右端、上・下・中央なら中央）。
- **サイズ:** それぞれの表示（タイル）の高さです（40〜200（以前は 24〜160）、4 刻み。既定 80（以前は 56）。macOS は pt、Windows は 96 DPI 換算の px）。
- **モニタ:** 表示するディスプレイを「アクティブなモニタ」（既定。マウスカーソルのあるディスプレイ。マウスカーソルと一緒に移ります）か「モニタ1」「モニタ2」…から選びます。つないでいるディスプレイの数だけ選択肢があり、分かる場合はディスプレイの名前を併記します（例:「モニタ1（DELL U2720Q・メイン）」）。番号は OS が認識しているディスプレイの順で、macOS はメインのディスプレイが「モニタ1」です。選んだディスプレイが接続されていない間は、アクティブなモニタに表示します。
- **入力感度**（「マイク入力」グループ。以前は「全般」グループ）**:** マイクの音量に対する、アイコンの反応の強さです（1〜10。既定: 5）。小さい音（ほとんど聞こえない程度の音）でもアイコンのレベルが高く表示される場合は下げ、大きな声でもあまり反応しない場合は上げます。
- **マイク:** OS の既定の入力デバイス（macOS はシステム設定の「サウンド」の「入力」、Windows は「サウンド」の設定で選んでいる録音デバイス）を自動的に使います。既定のデバイスを変えると、約 2 秒で切り替わります。音声は録音・保存せず、音量だけを読み取ります。
- **権限:** macOS は「マイク」の権限が必要です。初めて「マイク入力」を有効にしたときに許可を求められます。許可しなかった場合は、タブの「マイク入力」グループに注意と「システム設定を開く」ボタンが表示されます。使っている間は、メニューバーにマイクを使用中のオレンジの表示が出ます。Windows は、**設定 → プライバシーとセキュリティ → マイク** で「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」をオンにしてください。使っている間は、タスクバーにマイクを使用中のアイコンが表示されます。AI・CPU・メモリだけを表示する場合は、マイクを使いません（権限も不要です）。
- **表示の動作:** 表示はクリックを透過し（下のアプリをそのままクリックできます）、フォーカスを奪いません。Windows では、MiraCursor のキャプチャにも写ります（macOS では写りません）。
- **Bluetooth のヘッドセット:** マイク入力を使い始めると、ヘッドセットがハンズフリーのモードに切り替わり、音楽などの再生の音質が下がることがあります。
- **既定値に戻す:** 「ウィジェット」タブの「既定値に戻す」で、タブのすべての設定を初期値に戻せます（「管理」タブの「全て初期設定に戻す」でも戻ります）。
- **画面共有:** 画面に重ねて描くため、画面全体を共有している場合は相手にも映りますが、特定のアプリのウインドウだけを共有している場合は映りません（タブの上部に「⚠ ウインドウ共有時は反映されません」と表示されます）。

## 設定

| **キーモニタ**（新規） | 表示（見た目（以前の「方式」。スクロール / キーボード）・自動的に位置調整・位置（「モニタ」で選んだディスプレイの作業領域から見た 8 方向）・モニタ（既定: アクティブなモニタ）・距離・自動的に隠すまでの時間）、色（入力キーの色・未入力キーの色・未入力とみなすまでの時間・グラデーション表示の時間）、スクロール（幅・高さ）、キーボード（サイズ（キー 1 つ分の大きさ））、統計情報（有効・1分間 / 5分間 / 10分間 / 1時間 / 合計 / 削除キー）、既定値に戻す |

設定はすぐに反映されます（カスタムカーソルの設定と、各モードの「実行中はアイコンを変更する」などの一部の設定は、次にモードを開始したときから反映されます）。各タブの「既定値に戻す」で、そのタブの設定を初期値に戻せます。

## アップデート

MiraCursor は、新しいバージョンが公開されていると、**起動時に自動でアップデート** されます。

- **確認のタイミング:** 起動から約 3 秒後に 1 回だけ、[Releases](https://github.com/pd-labs-admins/MiraCursor/releases) の最新版を確認します。起動しているあいだに定期的に確認することはありません。実行中に自動で再起動して、プレゼンテーションを妨げないようにするためです。
- **インストール:** 新しいバージョンが見つかると、ダウンロードしてファイルの正しさ（チェックサム）を確かめます。そのあとインストールして、MiraCursor を再起動します。
- **プレゼン中はインストールしない:** 確認したときに強調表示モードの最中だった場合は、インストールしません（もう一度試すことはせず、次に起動したときに確認します）。
- **手動で確認する:** メニューの「アップデートを確認…」や、設定の「管理」タブの「今すぐ確認」から、いつでも確認してアップデートできます。この場合は、インストールの前に確認のダイアログが出ます。
- **自動インストールをやめる:** 設定の「管理」タブの「新しいバージョンを自動でインストール」をオフにすると、起動時の自動アップデートを行いません。
- **バージョンアップの内容:** 新しいバージョンが起動した初回だけ、そのバージョンの [Releases](https://github.com/pd-labs-admins/MiraCursor/releases) に書かれた説明文をそのまま表示します（「リリースページを開く」で GitHub のページも開けます）。MiraCursor は起動するたびにバージョンを記録していて、前回より新しいバージョンで起動したときに表示します。そのため、自動・手動のアップデートだけでなく、アプリを手動で入れ替えた場合（macOS でアプリを置き換えた場合や、Windows で MSI をインストールした場合）にも表示されます。説明文は、アップデートのときに保存しておいたものを使い、無い場合は GitHub から取得します。取得できなかった場合は、取得できなかったことを表示します（「リリースページを開く」で内容を確認できます）。アップデートに失敗して元のバージョンが起動した場合や、2 回目以降の起動では表示しません。設定の「管理」タブの「アップデート」グループの「アップデート内容の表示」（既定: オン。「自動更新」のすぐ下）をオフにすると表示しません（オフの間に保存しておいた説明文は破棄されるため、あとでオンに戻しても、表示しなかった説明文は表示されません）。

> **macOS をお使いの場合**
> アップデートのあと、「入力監視」（と「画面収録」）の許可をもう一度オンにする必要があることがあります。[よくある質問](#よくある質問トラブルシューティング) を参照してください。

## アンインストール

### macOS

1. メニューバーのアイコン →「MiraCursor を終了」を選びます。
2. アプリケーションフォルダの `MiraCursor.app` をゴミ箱に入れます。
3. 必要に応じて、次も削除します。
   - 設定ファイル: `~/Library/Preferences/net.pd-labs.MiraCursor.plist`
   - 任意の画像などのフォルダ: `~/Library/Application Support/MiraCursor`
   - **システム設定 → プライバシーとセキュリティ** の「入力監視」「画面収録とシステムオーディオ録音」にある MiraCursor（「−」で削除）

### Windows

1. タスクトレイのアイコンを右クリック →「MiraCursor を終了」を選びます。
2. **設定 → アプリ → インストールされているアプリ** で MiraCursor をアンインストールします。
3. 必要に応じて、設定のフォルダ `%APPDATA%\MiraCursor` を削除します。

## よくある質問・トラブルシューティング

<details>
<summary><b>macOS: 「入力監視」をオンにしているのに、権限が必要と表示される</b></summary>

macOS の許可は、アプリのコード署名に結び付いています。アップデートなどでアプリが置き換わると、一覧ではオンのままでも、許可が効いていない状態になることがあります。次の手順で許可し直してください。

1. **システム設定 → プライバシーとセキュリティ → 入力監視** で MiraCursor を選び、「−」で削除します。
2. 「＋」で `/Applications/MiraCursor.app` を追加し、オンにします。
3. MiraCursor を再起動します。

「画面収録とシステムオーディオ録音」も同じ手順です。
</details>

<details>
<summary><b>macOS: ズームで「画面収録の権限が必要です」と表示される</b></summary>

**システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で MiraCursor をオンにし、MiraCursor を再起動してください。macOS 15 以降では、許可を続けるかどうかの確認が定期的に表示されることがあります。
</details>

<details>
<summary><b>トリガーキーを長押ししても始まらない</b></summary>

- 設定の「キー設定」タブの「トリガーキー」グループで、そのモードのトリガーがあり、キーが登録されているか確認してください。**スポットライト・ズーム・キーモニタは、既定ではトリガーがない**ため、使う場合は「トリガーを追加」でトリガーを追加してキーを登録してください。メニューバー / タスクトレイのメニューで「未設定」と表示されているモードは、キーが登録されていません。
- 登録したキー **だけ** を押している必要があります。他のキーも一緒に押していると始まりません。
- 長押しの途中で他のキーやマウスボタンを押すと、ショートカット操作とみなされて始まりません。
- macOS では、「入力監視」の権限が必要です。
- Windows では、**管理者として実行しているアプリ**（タスクマネージャーなど）が前面にあるとき、Windows のセキュリティ機能によりキーを検出できません。他のアプリを前面にしてから操作してください。
</details>

<details>
<summary><b>macOS: カスタムカーソルの使用中にクリックすると、前に使っていたアプリのウインドウが消える / 右クリックのメニューが出る</b></summary>

終了方法が「キーを離す」のときは、モードの間トリガーキーを押したままになります。そのままクリックすると、macOS の標準の機能が働きます。

- **Option キーを押したまま他のアプリのウインドウをクリックすると、それまで使っていたアプリが隠れます**。トリガーキーに Option を含み、終了方法が「キーを離す」の場合（以前のカスタムカーソルの既定のトリガー（右 Option・キーを離す）など）、キーを押したまま他のアプリのウインドウをクリックすると、この動作が起こります。アプリは **隠れているだけで、終了していません**。Dock のアイコンをクリックするか、Command + Tab で切り替えると元に戻ります。
- **Control キーを押したままクリックすると、副ボタンのクリック（右クリック）として扱われます**。トリガーキーに Control を含む場合に起こり、右クリックのメニュー（コンテキストメニュー）が表示されます。

対処のしかた:

- カスタムカーソルの表示中に通常のクリックをしたい場合は、設定の「キー設定」タブの「トリガーキー」グループで、カスタムカーソルのトリガーの終了方法を **「キーの長押し」**、**「ESCキー」**、**「メニュー」** のどれかにしてください（これらの終了方法のトリガーを別のキーで追加することもできます）。長押しで始めたあとはキーを離してクリックできるため、右クリックになったり、アプリが隠れたりしません。
- または、カスタムカーソルのトリガーキーを Control・Option を含まないキーに変えてください（ただし、修飾キーを押しながらのクリックには、キーごとに macOS やアプリ独自の動作があります）。
- 終了方法が「キーを離す」で、トリガーキーに Option または Control を含むトリガー（ペンのトリガーを除く）には、「キー設定」タブのそのトリガーの行の下に注意が表示されます。
</details>

<details>
<summary><b>マウスカーソルの形が元に戻らない</b></summary>

カスタムカーソルモードでは、モードの間だけマウスカーソルの形を変えています（Windows では、ペン・ズームモードの「実行中はアイコンを変更する」も同じです）。万一 MiraCursor が異常終了してカーソルが戻らなかった場合は、MiraCursor を起動し直すと元に戻ります。

Windows のペン・ズームモードでは、各モードの設定にある「実行中はアイコンを変更する」をオフにすると、カーソルの形を変えなくなります。
</details>

<details>
<summary><b>特定のウインドウだけを共有すると、ペンやスポットライトが相手に映らない</b></summary>

ペン・スポットライト・ズーム・キーモニタ（とカスタムカーソルの残像・波紋）は、アプリのウインドウとは別のウインドウに描いているため、特定のアプリのウインドウだけを共有している場合は相手に映りません。次のどちらかの方法を使ってください。

- 画面全体（ディスプレイ / デスクトップ）を共有する
- [カスタムカーソル](#️-カスタムカーソル) モードを使う（マウスカーソルそのものを変えるため、ウインドウだけの共有でも相手に見えます）
</details>

<details>
<summary><b>ウィジェットのマイクのアイコンに斜線が引かれている</b></summary>

マイクを使えない状態です。次の点を確かめてください。

- マイク（入力デバイス）が接続されていて、OS の既定の入力デバイスになっていること（既定のデバイスを変えると、約 2 秒で切り替わります）。
- macOS: **システム設定 → プライバシーとセキュリティ → マイク** で MiraCursor がオンになっていること。
- Windows: **設定 → プライバシーとセキュリティ → マイク** で「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」がオンになっていること。
</details>

<details>
<summary><b>ウィジェットの「AI」の Claude Code・Codex を有効にできない / 「期限切れ」と表示される</b></summary>

Claude Code・Codex に OAuth でログインしている場合だけ有効にできます。スイッチの下に表示される理由を確かめてください。

- Claude Code: ターミナルで `claude` を起動し、Claude のアカウントでログインします。「利用状況を読む権限（user:profile）がありません」と表示される場合は、一度ログアウトしてログインし直してください。
- Claude Code (WSL)（Windows のみ）: WSL が起動している必要があります（止まっている WSL は起動しません）。WSL を起動し、WSL の中のターミナルで `claude` を起動してログインします。読むのは既定のディストリビューションの既定のユーザーの `~/.claude` だけです。「WSL がインストールされていません」と表示される場合は、`wsl -l` で既定のディストリビューションがあるかを確かめてください。
- Codex: ターミナルで `codex login` を実行し、ChatGPT のアカウントでログインします（API キーでのログインは対象外です）。
- ログインした後は、「AI」グループの「ログインの状態を再確認」を押してください。
- 「期限切れ（claude を起動）」「期限切れ（codex を起動）」と表示される場合は、Claude Code・Codex を一度起動してください（MiraCursor はログイン情報を更新しません）。
- 利用状況の API は公開されているものではないため、予告なく使えなくなる場合があります。
</details>

<details>
<summary><b>ウィジェットの「AI」のコストが、実際の請求額と違う</b></summary>

「本日」「30日間」のコストは、Claude Code・Codex がこのコンピュータに保存している会話の記録のトークン数に API の料金を掛けた目安です。

- 定額のプラン（Claude の Pro・Max、ChatGPT の Plus・Pro など）の請求額ではなく、同じ量を API の従量課金で使った場合の金額です。
- 料金表（models.dev）に無いモデルは数えません（0 円）。コンテキストの長さによる料金の違いも考慮しません。
- このコンピュータで使った分だけを数えます（ほかのコンピュータで使った分や、記録を削除した分は含みません）。
- 料金表・為替レートを取得できない場合は、組み込みの料金と 1 ドル = 150 円で計算します。
</details>

<details>
<summary><b>プレゼン中に自動でアップデートされることはありますか？</b></summary>

自動のアップデートは、**MiraCursor を起動したとき（起動から約 3 秒後）に 1 回だけ** 確認します。起動しているあいだに定期的に確認したり、自動で再起動したりすることはないため、プレゼンテーションの途中で突然アップデートされることはありません。

- 起動時の確認のときに強調表示モードの最中だった場合は、インストールしません。次に起動したときに、もう一度確認します。
- 手動でのアップデートは、いつでもできます。メニューの「アップデートを確認…」か、設定の「管理」タブの「今すぐ確認」を選んでください（インストールの前に確認のダイアログが出ます）。
- 起動時の自動アップデートも不要な場合は、「管理」タブの「新しいバージョンを自動でインストール」をオフにしてください。
</details>

<details>
<summary><b>ウイルス対策ソフトに警告された</b></summary>

MiraCursor は、トリガーキーの長押しを検出するために、キーボードとマウスの操作を監視しています。この仕組みについて、警告を出すウイルス対策ソフトがあります。MiraCursor はキー入力の内容を記録したり、外部に送信したりはしません（キーモニタモードの間だけ、押したキーを画面に表示します）。ネットワークへの通信は、アップデートの確認とダウンロード、バージョンアップの内容の取得（GitHub）と、ウィジェットの「AI」を有効にした場合の利用状況の取得（Anthropic・OpenAI）、コストの計算に使う料金表・為替レートの取得（models.dev・open.er-api.com）だけです。
</details>
